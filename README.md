# 鉄道運転シミュレータ

TypeScript + Three.js による鉄道運転シミュレータ。**現実の鉄道の仕組みと物理挙動を
可能なかぎり厳密に再現する**ことを目標にしている。

物理・信号コアと、それを実際に運転できるビューア（運転席一人称視点・外部検証視点・
時系列グラフ）まで実装済み。コアは描画に一切依存しない純粋な TypeScript なので、
別のフロントエンドへそのまま載せ替えられる。

## BVE との違い（設計の核）

1. **列車を単一質点ではなく多質点系として解く**
   各車両が自分の距離程で勾配・曲率を参照し、遊間と 2 段剛性を持つ連結器で結合する。
   長編成が勾配変化点を通過するときの前後衝動が、特別な処理なしに現れる。

2. **粘着を「力の頭打ち」ではなく輪軸の回転自由度として解く**
   各輪軸が独立した回転自由度を持ち、ピークと滑走域を備えたクリープ曲線を介して
   車体と結合する。空転・滑走は不安定現象として自然に発生し、再粘着制御や
   滑走防止装置が意味を持つ。

3. **すべての装置を「指令 → 応答遅れ → 実出力」として時間発展させる**
   ブレーキシリンダ圧のむだ時間と一次遅れ、回生失効と空気ブレーキへの受け渡し、
   トルク指令のレート制限を陽にモデル化する。指令した減速度が即座に出る、
   ということはない。

4. **音をサンプルではなく装置の仕組みから合成する**
   インバータの三角波比較 PWM を音声サンプルレート（48kHz）で実際に走らせ、
   その電圧波形から電動機の電磁加振力を求める。キャリア ± 出力周波数の
   サイドバンドも、非同期→同期のパルスモード切替も、一パルスの矩形波音も、
   個別に作り込まずに波形から出てくる。

5. **車体の揺れと乗客の振られ方を物理から出す**
   軌道狂いは「線路のその場所に固有の形状」として距離程の関数で持ち、
   車体はロール・ピッチ・ヨー・左右・上下の 2 次系として応答する。
   さらに乗客（吊り革）を**減衰振り子**として解くので、加速度に遅れて追従する。
   同じ減速度でも、ノッチを一気に入れれば乗客は振られて行き過ぎ、
   一段ずつ刻めば静かに傾くだけ — 運転の質がそのまま絵になる。

`75 mm 右上がり`（＝外軌が右）と `-4.03°` が表示され、車体はその上でさらにばねぶん傾く。
勾配区間では同じくピッチが「勾配 + 車体」に分かれる。

「乗客の振れ」は減衰振り子の角度で、括弧内の「遅れ」が瞬時の平衡角との差になる。
これが大きいほど乗客は振り回されている。B7 を一気に入れて G メータの振れ盤を見ると、
先端が平衡点を追い越して戻るのが軌跡に残る。

HUD のノッチ表示は **手元**（運転士が握っているハンドルの位置）と **実効**（保安装置・
戸閉め条件・ブレーキとの優先関係を通したあとに実際に主回路へ出る指令）を分けて出す。
力行ハンドルを入れているのに実効が「切」になる場合は、`力行カット` の表示とともに
その原因（保安装置の動作、ブレーキノッチとの重複、戸開）が読み取れる。

`O` で自動運転に入ると、HUD に装置の動作モード（力行 / 惰行 / 抑速 / 停止位置制御）と、
いま何を見て減速しているか、要求減速度と指令減速度が出る。切ったときは装置が握っていた
ノッチをそのままハンドル位置として引き継ぐので、制動中に切り替えても走り出さない。

## 物理モデルの要点

### 軌道線形

平面線形は曲率プロファイル κ(s) で定義し、方位角は θ(s) = θ₀ + ∫κ ds（解析的に厳密）、
平面位置は x = ∫cos θ ds, z = −∫sin θ ds をガウス・ルジャンドル求積で数値積分する。
直線・円曲線・緩和曲線（曲率が線形に変化）を同じ枠組みで扱える。
クロソイドの級数解と 10⁻⁶ の精度で一致することをテストで確認している。

縦断線形は勾配プロファイルの積分で高さを与える。縦曲線は勾配変化点を中心に
前後へ半分ずつ配置され、その区間の高さは s の 2 次関数（＝円曲線）になる。

### カント

カントは緩和曲線区間で逓減する。カント角は `φ = asin(C / G)` で、**外軌（曲線外側の
レール）が高いほど正**。曲率が正（左曲線）ならカントも正になる。一方、車体のロール角は
**右側が下がるほど正**という逆の約束なので、カントが車体に与えるロールは `−φ` になる。
描画も体感加速度もこの符号ひとつで決まるため、`apps/debugger/src/render/frame.ts` の
1 箇所だけで回転を作り、レール・まくらぎ・道床・車体・運転席カメラがすべてそこから
導かれるようにしてある（回帰テスト `apps/debugger/test/frame.test.ts`）。

軌道面内の非平衡左右加速度と均衡カントは厳密に整合する定義を採る。

```
a = v² κ · cos φ − g · sin φ                    非平衡左右加速度（正 = 外側へ）
tan φ_eq = v² κ / g,  C_eq = G · sin φ_eq       均衡カント（a = 0 になるカント）
C_d = C_eq − C                                   カント過不足（正 = 不足）
```

慣用式 `C = G V² / (127 R)` は `G · tan φ` に相当する小角度近似で、実用範囲では
厳密値より 0.5% ほど大きい。曲線の制限速度 `v = √((C + C_d,max) g R / G)` は
設計上の規則なのでデータ層で慣用式のまま扱う。

`cantDeficiency()` は**向き付き**の量（曲率と同符号なら外側へ超過遠心力）で、
右曲線では符号が反転する。実務で言う「カント不足量 [mm]」は左右によらない
スカラーなので、表示・警告・評価には `cantDeficiencyAmount()`（正 = 不足）を使う。

サンプル路線の曲線は実際の設計則に沿って与えてある。

| 曲線    | カント | 制限速度 | 均衡速度 | 制限速度でのカント不足 | C + C_d | 緩和曲線長          |
| ------- | ------ | -------- | -------- | ---------------------- | ------- | ------------------- |
| R600 左 | 75 mm  | 95 km/h  | 73 km/h  | 50 mm                  | 125 mm  | 80 m（逓減 1/1067） |
| R400 右 | 90 mm  | 80 km/h  | 66 km/h  | 43 mm                  | 133 mm  | 100 m（1/1111）     |

1067mm 軌間の上限（最大カント 105mm、最大カント不足 60mm、合計 165mm）に収まり、
緩和曲線長も設計則 `L ≥ 0.008 C V`（それぞれ 57m / 58m）を満たす。
均衡速度が制限速度の 0.77 / 0.82 倍というのも、カントを実際の運転速度に
合わせて決める実務の考え方と一致する。

### 列車ダイナミクス

車両ごとに位置と速度、輪軸ごとに角速度を状態として持つ。

- 車両: `m dv/dt = ΣF_creep + F_勾配 + F_連結器 − R_走行 − R_曲線`
- 輪軸: `J dω/dt = T_駆動 − T_ブレーキ·sgn(ω) − r F_creep(ω, v)`

クリープ力はすべり率に対して極めて急峻なため、輪軸は**後退オイラー法を
ニュートン反復で解く**。これにより dt = 1ms でも発散しない。
回転部慣性は等価質量係数 γ から `J = γ m_自重 r² / 軸数` として求めるので、
一定引張力での加速度が `a = F / (m(1+γ))` に厳密に一致する（テスト済み）。

軸重は静的な等分配に加えて、台車間（車体重心高さ）と台車内（牽引装置高さ）の
荷重移動を考慮する。どの軸から空転するかがこれで決まる。

### 粘着

```
ξ = (rω − v) / max(|v|, v_ref)
μ(x) = μ_k tanh(2x) + (μ_p − μ_k) · 2x/(1 + x²)      x = ξ / ξ_peak
μ_p(V) = μ₀ / (1 + kV) × 踏面状態係数 × 砂撒き係数
```

微小すべりで立ち上がり、ξ_peak 付近でピークを取り、大すべりで滑走摩擦係数へ
漸近する。この「ピークを越えると力が落ちる」形が空転・滑走を不安定現象にする。

### 車体の動揺と体感加速度

揺れの原因を 2 つに分けて扱う。

**軌道狂い** は距離程 s の関数として、波長の異なる正弦波の重ね合わせで生成する。
振幅を波長に比例させることで、軌道狂いのパワースペクトル密度が空間周波数の
-3 乗に比例するという実測の傾向に合わせている。時間の関数ではないので、
同じ地点を何度通っても同じ揺れ方になる。

**車体の応答** は各自由度を 2 次系（固有振動数と減衰比）として積分する。

```
ẍ = ω²(x_target − x) − 2ζω ẋ      ω = 2πf
```

| 自由度 | 目標値（励振源）                             | 既定の固有振動数 |
| ------ | -------------------------------------------- | ---------------- |
| ロール | 軌道面の横加速度 × 車体傾斜率 + 水準狂い     | 0.85 Hz          |
| ピッチ | 前後加速度 × ピッチゲイン + 前後台車の高低差 | 1.35 Hz          |
| ヨー   | 前後台車の通り狂いの差                       | 1.5 Hz           |
| 左右   | 横加速度 × ゲイン + 通り狂いの平均           | 1.0 Hz           |
| 上下   | 前後台車の高低狂いの平均                     | 1.2 Hz           |

乗客が感じる比力は、水平面での比力（右向き `a_h = v²κ`、上向き `g`）を、
**カントと車体ロールの両方で傾いた床**の座標系へ射影して求める。

```
φ = φ_軌道 + φ_車体          φ_軌道 = −カント角、    φ_車体 = ばね上のロール（右下がりが正）
p = p_軌道 + p_車体          p_軌道 = −勾配角、      p_車体 = ばね上のピッチ（前下がりが正）

felt_lateral      = a_h · cos φ + g · sin φ
felt_longitudinal = g · sin p − a · cos p
felt_vertical     = (g · cos φ − a_h · sin φ) · cos p + 上下動の加速度
```

左右も前後も同じ形で、**傾いた床に沿う重力成分**が加速度に加わる。

車体傾斜率（フレキシビリティ係数、空気ばね車で 0.3 程度）が大きいほど、車体は
曲線外側へ余分に傾き、乗客が感じる横 G は軌道面の値より大きくなる。これが車体傾斜制御が
必要になる理由でもある。逆に均衡カントちょうどで通過すると横 G は 0 になり、
上下 G が `g / cos φ` へ増える（曲線で体が重く感じられる現象）。

前後方向で勾配の項が効くのは、たとえば **33‰ の下り勾配を惰行しているとき**。
加速度だけを見れば `a = +0.32 m/s²` だが、斜面に沿う重力成分がこれを打ち消すので
乗客はほとんど何も感じない（残るのは回転部慣性のぶんだけ）。逆に上り勾配で停車すると、
加速度は 0 でも後ろへ押される。

### 乗客の振られ方（減衰振り子）

比力をそのまま角度に直す（`atan2(横G, 上下G)`）と、加速度が変わった瞬間に角度が飛び、
**加加速度（ジャーク）がまったく見えない**。実際の吊り革や立っている乗客は固有周期
1.5 秒程度の振り子で、加速度に遅れて追従する。そこで車体座標系の左右面・前後面それぞれで
減衰振り子を解く。

```
g_eff = hypot(f_i, f_z)
θ_eq  = atan2(f_i, f_z)                     瞬時の平衡角（= 加速度そのものの向き）
ω     = sqrt(g_eff / L)
θ̈     = −ω² sin(θ − θ_eq) − 2ζω θ̇ − φ̈_車体
```

- 復元項は非線形のまま。定常では `tan θ = f_i / f_z` に収束するので、減衰を強くすれば
  瞬時値表示に連続的に近づく
- `g_eff` を使うので、上下 G が増える曲線では振り子が硬くなる（周期が短くなる）
- `φ̈_車体` は車体のロール／ピッチ角加速度。吊り革の支点は車体と一緒に回るため、
  軌道狂いによる車体の揺れが吊り革を細かく揺らす
- 吊り革（下向きの振り子）と立っている乗客（支点が足元）は、支点の位置が違うだけで
  質量が動く向きは同じなので、同じ解を上下逆に描いている

結果として、**同じ減速度でもノッチの入れ方で絵が変わる**。一気に B7 を入れれば乗客は
大きく振られて行き過ぎ、揺り戻しが出る。一段ずつ刻めば同じ減速度でも静かに傾くだけになる。

### 表示

HUD はロールを「軌道 + 車体」、ピッチを「勾配 + 車体」に分けて出すので、傾きが
線形によるものか車体の揺れによるものかを区別できる。G メータは 3 つの図で構成する。

- **振れ盤** — 振り子の先端を真上から見た位置と軌跡。瞬時の平衡点を薄い十字で重ねてあり、
  両者を結ぶ線が「まだ振れ切っていない量」＝ジャークの効き具合になる
- **前面図** — カントで傾いた軌道面 → その上でロールした車体 → さらにその中で振られる
  吊り革と乗客、という 3 段が同時に見える
- **側面図** — 勾配で傾いた床 → 車体のピッチング → 前後に振られる吊り革

### ブレーキ

1. ノッチ → 指令減速度（定減速度制御）
2. 指令減速度 × 実際の等価質量 → 必要制動力（応荷重制御）
3. 空気ブレーキ指令を**先込め**する。回生が絞られてから込め始めると
   むだ時間と込め時定数のぶん減速度が落ち込むため、`むだ時間 + 込め時定数`
   だけ先の速度で見込まれる回生能力を基準に不足分を求める
4. BC 圧 = むだ時間 → 一次遅れ（込め／緩めで時定数が異なる）→ 摩擦材の μ(v)
5. 残りを電気ブレーキが受け持つ（空気が立ち上がるほど回生を絞る）
6. 滑走を検知した車の BC 圧を素早く抜き、収まったらゆっくり込め直す

回生絞り込み速度を跨ぐ受け渡しでは減速度がわずかに落ち込む。これは実車にも
現れる過渡であり、先込め制御によって指令値の 25% 以内に収まっている。

### 走行音

音源ファイルは 1 つも使わない。**装置の仕組みから波形を作る**という点で、
ほかのモデルと同じ方針を取っている。

#### インバータの変調（`packages/core/src/traction/modulation.ts`）

まず「いま主回路がどういうスイッチングをしているか」を物理から求める。
これは引張力には一切影響しない — 同じ出力をどう作っているかだけの話である。

```
f_rotor = p · (ω_軸 · 歯車比) / 2π         p = 極対数
f_slip  = f_slip,定格 · (T / T_定格)        力行で正、回生で負
f₁      = f_rotor + f_slip                 インバータ出力周波数
M       = min(1, f₁ / f_base)              V/f 一定 → 定電圧（弱め界磁）
```

角速度は**動軸の実回転**から取る。したがって空転すれば電動機の回転が跳ね上がり、
音も一緒に跳ね上がる（実車で空転が耳で分かるのはこのため）。

キャリア（スイッチング）周波数は、低速では出力周波数と無関係な**非同期**、
ある周波数から先は**同期**モードでキャリアを出力の整数倍に固定し、速度が
上がるにつれてその整数を段階的に落とす。この段階の切り替わりが、日本の VVVF 車で
聞こえる「音程が上がっていって途中でガクッと落ちる」の正体である。
モードはヒステリシス付きで選ぶ（境界で往復すると実機では素子が壊れる）。

サンプル車両（GTO サイリスタ、4 極・歯車比 7.07・車輪径 0.86m）の梯子:

| f₁     | モード         | キャリア                  | 目安速度 | 実測                                    |
| ------ | -------------- | ------------------------- | -------- | --------------------------------------- |
| 〜18Hz | 非同期         | 250 → 350 → 480Hz（段階） | 〜12km/h | 3.4 / 5.4 / 7.1 / 8.8 km/h で段が変わる |
| 18〜28 | 同期 15 パルス | 270〜420Hz                | 〜18km/h | 12.2km/h                                |
| 28〜38 | 同期 9 パルス  | 252〜342Hz                | 〜25km/h | 19.3km/h                                |
| 38〜47 | 同期 5 パルス  | 190〜235Hz                | 〜31km/h | 25.2km/h                                |
| 47〜53 | 同期 3 パルス  | 141〜159Hz                | 〜35km/h | 32.2km/h                                |
| 53〜   | 一パルス       | —                         | 35km/h〜 | 35.9km/h                                |

素子・変調方式はすべて車両データ側のパラメータなので、キャリアの表を高く平坦に
すれば IGBT に、階段状にすれば音階インバータになる。走りは 1 ミリも変わらない。

#### PWM 波形から音へ（`packages/audio/src/dsp/inverterVoice.ts`）

発振器を並べてキャリアとサイドバンドを 1 本ずつ作るのではなく、AudioWorklet の中で
実機と同じ手順を 1 サンプルずつ踏む。

```
1. 三角波キャリア c(θc) と 3 相の正弦変調波 m_x(θ₁) を比較して相電圧 ±1 を作る
2. 線間中性点電圧 v_an = v_a − (v_a+v_b+v_c)/3
3. 磁束 λ = ∫v_an dt              固定子電圧はほぼ磁束の微分
4. 電磁半径力 ∝ λ²                マクスウェル応力は磁束密度の 2 乗
5. 構造共振（固定子鉄心・フレーム）を通して放射音にする
```

**4 の 2 乗が要**である。`λ = λ₁ + λ_h` を 2 乗すると交差項 `2λ₁λ_h` が現れるので、
キャリア ± 出力周波数のサイドバンドと 2f₁ の磁気音が、個別に作り込まなくても
自動的に出てくる。同期モードへの移行も、過変調も、一パルスの矩形波音も、
比較の結果として現れるだけで特別扱いは要らない。

実際に node でレンダしてスペクトルを測ると、教科書どおりの構造になっている
（f₁ = 30Hz、キャリア 450Hz、いずれもゲルツェル法での実測値）。

| 周波数          | パワー          | 意味                                    |
| --------------- | --------------- | --------------------------------------- |
| 60Hz            | 1.0e-3          | 2f₁ の磁気音                            |
| 420 / 480Hz     | 2.6e-6 / 2.1e-6 | キャリア ± f₁                           |
| 360 / 540Hz     | 2.1e-6 / 4.7e-6 | キャリア ± 3f₁                          |
| **450Hz**       | **2.7e-15**     | キャリアそのもの — 3 相で打ち消される   |
| **390 / 510Hz** | **2e-13**       | 偶数次サイドバンド — 同じく打ち消される |

磁束は 3 相の打ち消しで奇数次しか持たず、それを 2 乗した力は**必ず偶数次**になる。
「回転数の 2 倍のうなり」が実車で聞こえるのはこれである。

V/f 一定制御では変調率が `f₁/f_base` で上がるため、磁束 `M/f₁` は基底周波数まで
一定に保たれる。以降は変調率が飽和して磁束が `1/f₁` で落ちる。**低速でも音が痩せず、
弱め界磁に入ると磁気音が弱まる**という実機の関係が、この 1 行から出る。

比較器の出力は理想的な矩形波なので、そのままの速度で作ると折り返しが可聴帯域に
落ちる。PWM 生成から 2 乗までを 4 倍オーバーサンプリングで行い、帯域が倍に
広がった後で低域通過させて間引く。

#### そのほかの音源

| 音源             | 駆動する量                 | 速度依存                                                   |
| ---------------- | -------------------------- | ---------------------------------------------------------- |
| 歯車のかみ合い   | 電動機回転数 × 小歯車歯数  | 周波数が回転数に比例。1 回転ごとの歯形誤差でうなる         |
| 転動音           | 車輪・レールの粗さ         | 30·log₁₀v（振幅 ∝ v^1.5）。重心も速度で上がる              |
| 風切り音         | 空力音                     | 60·log₁₀v（振幅 ∝ v³）。通勤形の速度域では転動音に埋もれる |
| レール波状摩耗   | 踏面の周期的な摩耗         | `v / 波長` の狭帯域の唸り。加速すると音程が上がる          |
| まくらぎ通過     | レールの支持剛性の周期変化 | `v / 0.6m` で転動音が脈動する                              |
| レール継目       | 軸が継目を踏む時刻         | 衝撃の強さ ∝ v^1.5                                         |
| ブレーキ摩擦     | 押付力 × すべり速度        | 止まる寸前に消えるのは速度が 0 になるから                  |
| 制輪子の鳴き     | 低速 × 高い押付力          | 摩擦係数の速度勾配が負になる領域の自励振動                 |
| 空気の込め／排気 | BC 圧の**変化率**          | 緩め（大気開放）のほうが込めより大きい                     |
| 空気圧縮機       | 元空気溜め圧               | 運転操作と無関係な周期で突然回り出す                       |
| 空気ばねのきしみ | 車体の上下・ロール速度     | ゴムのスティックスリップ。**遅く**擦れるときだけ鳴く       |
| 保安装置の報知音 | ベル・チャイム・パターン   | 運転台の中で鳴るので距離減衰もマスクも受けない             |
| 警笛             | 吹鳴の操作                 | 空気笛 2 管の和音。圧力の立ち上がりで音程が動く            |
| トンネル         | 編成が坑内に入っている割合 | 合成した減衰雑音の IR で残響を付ける                       |

**惰行するとインバータ音だけが消えて歯車と転動音が残る。** これがインバータ音と
走行音の決定的な違いで、ノッチを切った瞬間に音程がすっと消えるのはこのため。

最後の段は「力 → 音」の変換で、ここが 2 つに分かれる。**構造共振**（固定子鉄心と
フレームのモード）が力を振動に変え、**放射効率**が振動を音に変える。放射効率は
一致周波数（曲げ波の速度が音速に追いつく周波数、鋼板で 2.5kHz 前後）より下では
f² に比例して低い — 板が動いても空気が横へ逃げてしまうためで、これを入れないと
高速域が実際よりはるかに静かになる。弱め界磁で磁束が 1/f₁ に落ちるので力は
−40·log₁₀f で減る一方、成分は高域へ動いていくので、放射効率の +6dB/oct が
その半分を打ち消す。実車で高速でも電動機の音が聞こえ続けるのはこの釣り合いによる。

ノッチの入切は、音量ではなく**ゲート（相電圧）**で表している。切れば素子が全部
オフになって電圧が 0 になり、磁束は還流ダイオードを通って電動機自身の時定数で
減衰する。つまり消え方そのものが過渡であって、包絡線を別に用意していない。
入れるときは逆に磁束が立ち上がる。**出力周波数はゲートが閉じているあいだも
回転子の周波数を渡し続ける** — 0 へ落とすと、磁束が積分（利得 ∝ 1/f）である
ために消えぎわで利得が跳ね上がり、80km/h では定常の 14 倍もの掃引音（「ピッ」という
異音）が出る。実機の再投入も、回っている回転子の速度に合った周波数から入る。

#### レールから来る音

レール継目は、軸ごとに「前ステップと今ステップのあいだを跨いだか」で判定し、
フレーム内の位置を小数で求めて**サンプル精度**で予約する。60fps に丸めると 16ms も
ばらついて「ガタン ゴトン」の間隔が台車の寸法を映さなくなる。1 両 4 軸なら
前台車の 2 軸（固定軸距 2.1m）→ 間を空けて → 後台車の 2 軸、という 2 拍ずつの
並びになり、続いて次の車両が同じ継目を踏む。

1 回の衝撃は**別々の経路**を通って音になる。経路ごとに関わる質量とばねが違うので、
周波数だけでなく**残る長さ**も違う。低次のモードほど減衰が小さいという構造振動の
一般則がそのまま「ガタン」の重さになっている。

| 経路                         | 周波数 | 残る長さ | 聞こえ方 |
| ---------------------------- | ------ | -------- | -------- |
| ばね上（車体）とレールの曲げ | 80Hz   | 250ms    | ガ〜     |
| 台車枠・軸箱（ばね下）       | 230Hz  | 90ms     | タン     |
| 車輪踏面とレール腹部         | 1500Hz | 18ms     | カッ     |

3 つを同じ短い時定数で減衰させていたころは低域が高域と一緒に切れてしまい、
「カタッ カタッ」という軽い音にしかならなかった（低域/高域 +7.8dB、−20dB まで
110ms）。経路ごとに分けた結果 +23dB / 200ms になっている。

継目の無いロングレール区間では、代わりに**レール自身から来る 2 つの音**が主役になる。
どちらも周波数が速度に比例するので、加速すると音程が上がっていく。

- **波状摩耗（コルゲーション）** — 踏面には走行を重ねるうちに波長数 cm の周期的な
  摩耗ができる。粗さのスペクトルにその波長の峰が立つので、転動音に `v / 波長` の
  狭帯域の唸りが乗る。55mm なら 60km/h で 303Hz、120km/h で 606Hz。深さは路線
  データの区間属性なので、「この区間は唸る」を線路の側で表せる
- **まくらぎ通過** — レールはまくらぎの上では硬く、間では柔らかい。この支持剛性の
  周期変化が接触力を脈動させるので、転動音の包絡が `v / 0.6m` で揺れる

#### 運転台の中で鳴るもの

保安装置の報知音（打鈴・チャイム・パターン接近ブザー）と警笛だけは、**運転台の
中の装置**が音源なので距離減衰を受けない。走行音に埋もれてしまっては装置の意味が
無いのだから、走行音より大きいのは都合ではなく設計である。実測でも 80km/h の
走行音に対して報知音が +4dB、警笛が +8dB（いずれも A 特性）に置いてある。

打鈴は電磁ベルで、電磁石がハンマーを引き、接点が切れて戻り、また引く、という
自励で毎秒 32 回連打する。鐘の部分音は整数比に**ならない**ので、「ジリリリ」が
音程を持たずに耳につく。正弦を重ねただけでは電子音になってしまう。

警笛は空気笛（タイフォン）で、圧縮空気がリードを振動させる。倍音が豊かなことと、
2 管の周波数がわずかにずれていてうなりが乗ることが「ブザーとの違い」を作る。
吹き始めは弁が開いてから圧力が立ち上がるまで音程がわずかに低い。

空気ばねのきしみは、分厚いゴムのベローズが金属座と擦れる音である。ゴムは静摩擦が
動摩擦よりかなり大きいので擦れが滑らかに進まず、固着と滑りを繰り返す — 制輪子の
鳴きとまったく同じスティックスリップで、**遅く擦れるときにだけ**鳴く。速く滑ると
固着する暇が無いので鳴かない。車体の上下速度とロール角速度から左右の空気ばねの
ストローク速度を求めて駆動するので、停車前後や低速の曲線でだけ耳に届く。

#### 音量バランス

音源どうしの音量は**耳ではなく実測で**決めてある。耳で合わせると、そのとき鳴って
いない音源を基準にしてしまう。実際、空気圧縮機は停車中に合わせたせいで 80km/h の
走行音より大きくなっていた（rms 0.076 対 0.067）。走行音を基準に測り直して 10dB 下へ
置き、`packages/audio/test/synth.test.ts` の回帰テストで固定してある。

運転台の `音量バランス` に調整用のつまみとメータがある。メータは**混ざる前の**
音源ごとの実効値（`TrainNoiseSynth.readLevels`）なので、「うるさい」と感じたものが
本当にその音源なのか、走行音に対してどれだけ大きいのかが数値で分かる。

走行装置は歯車・転動音・風切りを別々の音源として持つ。**音源の位置が違う**ため
まとめられない — 歯車は M 車の床下にしか無いので運転台からは編成の中ほどの
距離だけ離れており、転動音は運転台の真下の軸からも来る。分けて測って初めて、
それまで見えていなかった 2 つの誤りが分かった。

|                  | 分ける前                | 分けたあと                                                |
| ---------------- | ----------------------- | --------------------------------------------------------- |
| 歯車 vs 転動音   | 歯車が 120km/h まで支配 | 逆転点が 50km/h（低速では歯車、高速では転動音）           |
| 風切り vs 転動音 | 90km/h で風切りが逆転   | 最高速度でも 10dB 下（空力音が支配するのは 250km/h 以上） |

力行と惰行の差を決めるつまみが 2 つある。どちらも仕組みのある量である。

- **インバータの負荷追従** — V/f 一定制御では磁束が保たれるので、実機の磁気音は
  負荷でそれほど変わらない。0 にすればゲートが開いているあいだ一定になる。
  惰行ではどのみちゲートが閉じるので音は消える
- **歯車の負荷追従** — 裏を返せば「惰行のとき歯車が全負荷の何割を受け持つと
  見なすか」。惰行でも回転部の慣性トルクが歯面に掛かるので 0 にはならない

### 保安装置

- **ATS-SN**: ロング地上子で警報 → 5 秒以内に確認扱いが無ければ非常。
  直下地上子を停止現示で通過すると即時非常。確認扱いさえすれば冒進できてしまう
  という性質も含めて再現している。
- **ATS-P**: 地上子から目標地点までの距離と目標速度を受け取り、車上でパターンを
  生成して連続照査する。パターン速度は応答時間 t_r を含む
  `v² = v_t² + 2a(d − margin − v·t_r)` の**厳密解**
  `v = −a t_r + √(a²t_r² + v_t² + 2a(d − margin))` で求める。
  停止信号・速度制限・線路終端・信号冒進に対応。
- **ATC**: 段階式（現示速度以下に落ちるまで緩解しない）とデジタル式
  （停止点からの一段ブレーキパターン）。
- **EB 装置**: 無操作の監視 → 警報 → 非常。

地上子の通過は「その瞬間に一致したか」ではなく**前ステップ位置と現ステップ位置の
区間を跨いだか**で判定するため、高速走行でも取りこぼさない。

列車が信号機を通過した瞬間、その列車自身が次の閉塞に入るため信号は停止現示へ
変わる。冒進判定には「まだ手前の閉塞にいた時点の現示」を使い、正常に進行現示で
通過した列車を誤判定しないようにしている。

停止現示の手前で止まった列車は、パターンの余裕距離の内側に次の地上子が無く、
パターン速度も 0 なので、そのままでは現示がアップしても動き出せない。停車中に
限り、現示アップでその信号のパターンを解放する（実機の直下地上子による消去に相当）。

### 自動運転（ATO / TASC）

`packages/core/src/operation/autoDrive.ts`。運転士の代わりに `ControlInput` を組み立てる
だけの装置で、物理にも保安装置にも手を入れない。したがって自動運転で走らせても、
出てくる挙動は手動運転とまったく同じ物理モデルの上の結果になる。

設計は「**不自然なブレーキの入切をしない**」と「**停止の衝撃を小さくしたまま停止位置に
収める**」の 2 点を軸にしている。

**1. 速度ではなく必要減速度で考える**

「目標速度を超えたらブレーキ、下回ったら緩解」という制御は、目標速度の周りで必ず
ブレーキを入切する。そこで前方の減速目標（速度制限・停止現示・停止位置）に対して

```
a_req = (v² − v_t²) / 2(d − margin − v·t_lag)
```

という**その目標に届くのに必要な減速度**を求め、それがそのまま出るノッチを選ぶ。
必要減速度どおりに減速しているかぎり a_req は一定に保たれるので、ノッチを動かす
必要がない。空走時間 t_lag は込める前は応答時間そのもの、込めたあとは 0 へ減らす
（込めたあとも引き続けると、目標へ近づくほど必要減速度が過大に出てノッチが
際限なく深くなる）。

**2. 勾配と走行抵抗を打ち消してから指令する**

ブレーキ装置の指令減速度は「ブレーキが受け持つぶん」であり、実際の減速度には勾配と
走行抵抗が加わる。指令値から勾配ぶんを差し引いておくと、下り勾配でもノッチを
入れっぱなしのまま速度が保たれる。33‰ の下り勾配は電気ブレーキだけの**抑速**で
受け持つので、空気ブレーキは 1 度も入切しない。

**3. 止まる直前は減速度そのものを絞る（衝撃緩和）**

停止の衝撃は「止まった瞬間の減速度」がそのまま前後衝動になる。速度に対する目標減速度を

```
a(v) = a_final + (a_stop − a_final)·min(v / v_ease, 1)
```

と定め、その形のまま止まったときの制動距離を解析的に求める。絞り込み域では
`a(v) = a_f + c·v` なので

```
D(v) = ∫₀^v u/(a_f + c u) du = v/c − (a_f/c²)·ln(1 + c v / a_f)
```

となる。残距離 d に対する指令は `a(v)·D(v)/d` でよい。ちょうど良い位置（d = D(v)）なら
そのまま a(v) が出て、ずれていれば比例して補正される。これは一定減速度の必要減速度
`a = v²/2d` の自然な拡張であり、**停止位置の精度を落とさずに**止まる瞬間の減速度だけを
a_final まで落とせる。ノッチは B5 → B4 → B3 → B2 と自然に緩んでいく。

そのほか:

- ノッチは 1 段ぶんの減速度に対する不感帯と最短間隔つきでしか動かさない。込めるときは
  一度に 2 段までで、足りなければ短い間隔で続ける（電気ブレーキは指令に即座に応じる
  ので、深いノッチを一息に入れると同じだけの段差が減速度に出る）
- 指令に対して実際に出ている減速度の比を覚えておき、雨・雪で滑走防止装置が働いて
  効きが落ちているぶんを割り増して補う。ただし絞り込み域では割り増さない
  （粘着が戻った瞬間に過大な減速度となって現れるため）
- 保安装置の照査速度も速度の上限に入れる。自動運転装置が保安装置に止められる、
  というのが運転としても保安としても最悪で、そこだけ突然の常用最大が入ってしまう
- 停車時分と発時刻の両方を満たしてから戸閉めし、戸閉め確認の間をおいて発車する。
  終着駅では発車しない。ATS-SN 区間では警報に確認扱いをする
- 空転・滑走を検知したら砂を撒く

試験線を自動運転で走らせた実測（晴天・4 両）:

| 指標                     | 値                          |
| ------------------------ | --------------------------- |
| 停止位置誤差             | +0.22m / +0.26m（許容 1m）  |
| 止まった瞬間の減速度     | 0.07 m/s²（常用最大の 1/14) |
| ブレーキを込めた回数     | 3 回（＝停車回数）          |
| ブレーキノッチの操作回数 | 19 回（7km・3 停車）        |
| 保安装置の動作           | 0 回                        |

降雪（粘着が落ち、滑走防止装置が動作し続ける条件）でも停止位置誤差は 0.02m 以内に
収まる。ブレーキの効きの推定が働くため。

## 決定論

コアは `Date.now()` も `Math.random()` も使わない。乱数はシード付き mulberry32、
時刻は引数で渡す。未消化時間は整数マイクロ秒で保持するため、`step()` の呼び出し
間隔（フレームレート）を変えても結果がビット単位で一致する。

したがって「シナリオ ID + シード + 入力の変化列」だけで走行を完全に再現できる。
ビューアの「記録を保存 / 読込」はこれを使っている。

## データ形式

路線・車両・シナリオは zod スキーマで定義し、**現場で使われる単位**
（km/h・‰・mm・t・kgf/t・kPa・km/h/s）で書く。コンパイラが SI へ変換する。
経験式の係数はコードに埋めず、すべてデータ側のパラメータとして持つ。

路線データからは次が自動生成される:

- 曲線の制限速度（許容カント不足から `v = √((C + C_d) g R / G)`）
- ATS-P の地上子（信号機・速度制限の手前の指定距離へ）
- ATS-SN の地上子（ロング・直下）
- 閉塞区間（信号機の位置から導出）

同梱サンプル: 架空の試験線（8km、R600/R400 曲線、25‰ 上り・33‰ 下り、
トンネル、駅 3、閉塞信号 8）と通勤形 4 両編成（2M2T、起動加速度 3.3km/h/s、
常用最大減速度 3.5km/h/s、非常 4.5km/h/s）。

新しい路線を足すには `packages/data/src/assets/` に定義を書き、
`createDefaultLibrary()` へ登録する。

## 検証

`npm test` で 100 件超のテストが走る。主なもの:

**解析解との突き合わせ**

- 惰行減速が走行抵抗の常微分方程式を 4 次ルンゲ・クッタで積分した解と一致
- 勾配のみで `a = g sinθ / (1+γ)`
- 一定引張力で `a = F / (m(1+γ))`
- 曲線抵抗が `f / R` に一致し、半径に反比例
- 円曲線の弧長・座標、クロソイドの級数解、縦曲線の高さ
- 停止距離が `v²/2a` + 空走距離の範囲に収まる
- ATS-P パターンが 2 次方程式の厳密解と一致

**現象テスト**

- 降雪条件の全ノッチ起動で空転が発生し、再粘着制御が引張力を絞る
- 砂撒きで粘着が回復する
- 粘着条件が悪いほど非常制動距離が延びる（乾燥 168m → 降雪 267m → 落葉 342m）
- 滑走防止装置を切ると制動距離が悪化する
- 電空協調の受け渡しで減速度が保たれる／回生失効しても空気が補う
- 先行列車が進むと後方の信号が段階的に現示アップする
- ATS-P が停止信号の手前で列車を止め、非常ブレーキには至らない
- 停止現示の手前で止まった列車が、現示アップ後に発進できる

**自動運転**

- 起点から終点まで自分で走り、全駅の停止位置に**所定内**（許容 1m）で止まる
- 止まる瞬間の減速度が常用最大の 1/5 以下（＝停車の衝撃緩和）
- 止まる直前ほどブレーキノッチが浅くなる
- ブレーキを込め直す回数が停車回数程度に収まる
- 33‰ の下り勾配を抑速で通過し、そのあいだ空気ブレーキを 1 度も入切しない
- 降雪でブレーキが効きにくくても停止位置に収まる（効きの推定が働く）
- 停止現示の手前で自分で止まり、現示アップで自分で発進する
- 停車時分と発時刻の両方を満たしてから発車する
- ATS-SN 区間では確認扱いを行い、非常ブレーキに至らない
- 保安装置（パターン・非常・EB）を一度も動作させずに走り切る
- 呼び出し間隔（フレームレート）を変えても状態ハッシュが一致する

- 曲線で車体が外側へロールし、体感横 G が軌道面の値を上回る
- 車体傾斜率を 0 にすると体感横 G が軌道面の値と一致する
- 加速で乗客は後ろへ、制動で前へ押され、車体がピッチングする
- 軌道狂いが大きいほど揺れが大きく、狂いゼロなら揺れない

**勾配と乗客の振れ**

- 上り勾配で停車していると、加速度 0 でも乗客は後ろへ押される
- **33‰ を自由に転がっているときは前後の比力がほぼ 0**（勾配の重力成分が入っている証拠。
  抜けていると `-a = -0.32 m/s²` と出る）
- 一定加速度で振り子が `tan θ = a/g` へ収束し、平衡角は瞬時値と一致する
- 加速度を変えた直後は平衡角に届いていない（＝加加速度が見える）
- 減衰を弱くすると行き過ぎ、強くすると行き過ぎない
- 減衰をほぼ 0 にすると固有周期が `2π√(L/g)` に一致する
- 振り子が短いほど速く追従する
- 制動では前へ、力行では後ろへ振れる

**走行音（node でオフラインレンダしてスペクトルを測る）**

- 非同期モードでキャリア ± f₁ と ± 3f₁ にサイドバンドが立つ
- 3 相の打ち消しでキャリアそのものと偶数次サイドバンドが消える
  （1 相だけで作っている実装ならここで落ちる）
- 電磁力が出力周波数の**偶数倍にしか現れない**
- 同期モードでは全成分が f₁ の整数倍に乗り、その間には何も無い（位相ロックの確認）
- 一パルスではキャリアの帯が消え、低次の偶数次高調波だけになる
- 弱め界磁で磁気音が弱まり、基底周波数以下では低速でも痩せない
- **最高速度でも電動機の音が走行音に埋もれきらない**（A 特性で測る。放射効率と
  2.4kHz 以上の構造モードが無かったころは 27dB 下に沈んで聞こえなくなっていた）
- オーバーサンプリングを切ると折り返し成分が増える
- 歯車のかみ合い周波数とその高調波、歯形誤差による 1 回転ごとの側帯波
- 惰行しても歯車の音が消えない／電動機が回っていなければ歯車は無音
- 転動音が速度 2 倍で 9dB 増える（30·log₁₀v）
- 風切り音が速度 2 倍で 18dB 増え（60·log₁₀v）、最高速度でも転動音より 6dB 以上下
- **低速では歯車、高速では転動音が支配する**（まとめて 1 つの音量にしていたころは
  歯車が高速域まで支配したままだった、という回帰テスト）
- 継目の衝撃が予約したサンプル位置ちょうどから鳴り、**走行音に混ざっても突出する**
  （帯域通過の正規化で衝撃が埋もれるという不具合の回帰テスト）
- 継目の衝撃で**低い成分ほど長く残り**、低域・中域が高域より強い
  （すべて同じ時定数で減衰させて「カタッ」と軽くなっていたことの回帰テスト）
- 「ガタン ゴトン」の間隔が固定軸距・台車中心間距離と一致する
- ロングレール区間では継目が 1 つも出ない／逆走でも取りこぼさない
- 波状摩耗が `v / 波長` に唸りを作り、速度を変えると峰が動く／削正されたレールでは唸らない
- まくらぎ通過で転動音の包絡が `v / 0.6m` の周期で脈動する
- 空気ばねのきしみが「動いてはいるが遅い」ときにだけ出る（速く滑ると鳴かない）
- 打鈴・チャイム・ブザーが独立に鳴り、いずれも 80km/h の走行音より大きい
- 打鈴がハンマーの打数で脈動する（持続音になっていない）
- 警笛が 2 管の和音になっていて倍音を持ち、離すと圧力が抜けて消える
- 空気圧縮機が断続運転し、ブレーキを使うほど早く回り出す
- **ノッチを切っても入れても、過渡が定常より大きくならない**
  （出力周波数を 0 へ落として掃引音が出るという不具合の回帰テスト）
- 空気圧縮機が 80km/h の走行音より 6dB 以上小さく、かつ聞こえないほどでもない
- レベルメータが混ざる前の値を音源ごとに返す

**カント**

- 均衡カントが釣り合い条件 `tan φ = v²κ/g` を満たし、そのとき非平衡横加速度が厳密に 0
- 均衡カント通過時は体感横 G が 0、体感上下 G が `g / cos φ`（1G より重い）
- 停車中の曲線ではカント超過となり、乗客は曲線内側へ引かれる
- 描画の基準座標系で、左曲線は右側が上がり、右曲線は左側が上がる
  （車体とレールが逆向きに傾くバグの回帰テスト）
- 基準座標系が正規直交で、勾配区間でも軌道面が軌道に垂直になる

**性質テスト**

- 同一入力・異なるフレームレートで状態ハッシュが完全一致
- 軌道狂いは距離程の関数なので、同じ地点では常に同じ値になる
- 記録した入力の再生で同じ走行になる
- 連結器を硬くすると多質点モードが剛体モードへ漸近する

**性能**

`npm run bench` の実測で、4 両編成（16 軸）を物理 1kHz・装置制御 100Hz で回して
リアルタイム比 約 100 倍（10 秒ぶんの走行を 96ms）。多質点モードと単一質点モードの
差はほとんど無く、計算量は輪軸のニュートン反復が支配している。

## ビューア

- **運転席一人称視点** — 先頭車の前端・左側の運転士の目線。車体動揺をそのまま
  カメラに反映する（補間しない）ので、曲線でのロールも軌道狂いによる揺れも
  視界に出る。内装はカメラの子として取り付けてあるため、実車と同じく
  「内装は視界の中で静止し、窓の外だけが揺れる」。指針式の速度計・圧力計・
  電流計と、ノッチに連動するマスコン／ブレーキ設定器、ATS 表示灯を備える。
- **外部視点**（追跡・側面・俯瞰・自由）— 列車と線路の関係を確かめる検証用。
- **昼間の沿線景観** — グラデーションの空、緑地、樹木・建物（シードから決定論的に
  配置）、架線柱とトロリ線、トンネル覆工、100m 距離標、駅ホームと上屋。
- **加速度メータ** — 前後 G と左右 G を 1 点で表す G サークル（軌跡付き）、
  ロール角ぶん傾いた車体断面に吊り革と立っている乗客を描いた前面図、
  ピッチングと前後の振られを示す側面図。数値ではなく「乗客がどちらへ
  どれだけ振られるか」を直接見せる。
- **時系列グラフ** — 速度・制限・ATS-P パターン、ノッチ、引張力と電空の分担、
  抵抗の内訳、BC 圧、すべり率と再粘着制御、インバータの出力周波数・キャリア・
  パルス数、体感加速度と車体ロール、連結器力と車体の揺れ。
- **走行音** — インバータ・主電動機・歯車・転動音・レール継目・ブレーキ・
  空気・補機・風切り・トンネルの反響。HUD の「変調」「出力 / すべり」と
  グラフの「インバータ」帯を見れば、鳴っている音が仕様どおりかを目で確かめられる。
- **自動運転** — `O` で入切。装置の動作モードと、いま何を見て減速しているか、
  要求減速度と指令減速度を HUD に出す。手動運転と見比べれば、ノッチの入切の
  少なさと、止まる瞬間の減速度の小ささが G メータの振れ盤にそのまま出る。
