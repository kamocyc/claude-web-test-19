# 鉄道運転シミュレータ

TypeScript + Three.js による鉄道運転シミュレータ。**現実の鉄道の仕組みと物理挙動を
可能なかぎり厳密に再現する**ことを目標にしている。

物理・信号コアと、それを実際に運転できるビューア（運転席一人称視点・外部検証視点・
時系列グラフ）まで実装済み。コアは描画に一切依存しない純粋な TypeScript なので、
別のフロントエンドへそのまま載せ替えられる。

## BVE との違い（設計の核）

1. **列車を単一質点ではなく多質点系として解く**
   各車両が自分の距離程で勾配・曲率を参照し、遊間と 2 段剛性を持つ連結器で結合する。
   長編成が勾配変化点を通過するときの前後衝動が、特別な処理なしに現れる。

2. **粘着を「力の頭打ち」ではなく輪軸の回転自由度として解く**
   各輪軸が独立した回転自由度を持ち、ピークと滑走域を備えたクリープ曲線を介して
   車体と結合する。空転・滑走は不安定現象として自然に発生し、再粘着制御や
   滑走防止装置が意味を持つ。

3. **すべての装置を「指令 → 応答遅れ → 実出力」として時間発展させる**
   ブレーキシリンダ圧のむだ時間と一次遅れ、回生失効と空気ブレーキへの受け渡し、
   トルク指令のレート制限を陽にモデル化する。指令した減速度が即座に出る、
   ということはない。

4. **音をサンプルではなく装置の仕組みから合成する**
   インバータの三角波比較 PWM を音声サンプルレート（48kHz）で実際に走らせ、
   その電圧波形から電動機の電磁加振力を求める。キャリア ± 出力周波数の
   サイドバンドも、非同期→同期のパルスモード切替も、一パルスの矩形波音も、
   個別に作り込まずに波形から出てくる。チョッパ音も同じで、通流率の方形波から
   リップル電流を作れば「音程が速度に依らず、全通流で消える」が自然に出る。

5. **制御方式を主回路の作りから解く**
   VVVF インバータのほかに、直流直巻電動機を使う抵抗制御と電機子チョッパを持つ。
   直流機では引張力を指令しない — 磁化曲線と電機子回路の微分方程式を解いた結果として
   出てくる。抵抗制御の鋸歯状の引張力も、直並列切替でトルクが抜ける渡りも、
   発電ブレーキが低速で落ちるのも、そこから勝手に現れる。

6. **車体の揺れと乗客の動きを物理から出す**
   軌道狂いは「線路のその場所に固有の形状」として距離程の関数で持ち、
   車体はロール・ピッチ・ヨー・左右・上下の 2 次系として応答する。
   吊り革は**減衰振り子**、立っている乗客は**倒立振子 + 0.14 秒のむだ時間を持つ
   姿勢制御**として別々に解く。人は物と違って先によりかかって耐えるので、
   加速度をゆっくり変えれば踏ん張れるが、急に変えれば取り残されて足が出る。
   同じ加速度でも**変え方**で結果が変わる — 運転の質がそのまま絵になる。

同梱シナリオには**同じ路線を 4 種類の車両で運転する**ものが入っている。
「試験線 各駅停車（晴天）」が VVVF、「（抵抗制御）」がカム軸進段の旧型、
「（電機子チョッパ）」が抵抗制御車と同じ電動機を段なしで回す車である。
抵抗制御車で力行すると HUD の「制御」行に `直列 5/19 段` のように段が出て、
引張力のグラフに鋸歯が、渡りには一瞬の欠けが現れる。「（抵抗制御・降雪）」では
架線の回生受け入れ率が落ちるが、**発電ブレーキなので効きは変わらない** —
同じ条件の VVVF 車（「（降雪）」）と乗り比べると違いがそのまま出る。

「（音階インバータ）」は走行性能が「（晴天）」とまったく同じで、**変調の諸元だけ**が
違う車である。力行すると起動から 40km/h あたりまでキャリア周波数が平均律の音名を
階段状に上っていき（ソラシド レミファソ ラシドレ）、減速すれば同じ階段を下りてくる。
走りが 1 ミリも変わらないのに音だけが変わることが、そのまま確かめられる。

`D` で客用扉を開け閉めできる。閉指令を出すとまずドアチャイムが鳴り、少し置いてから
扉が動き出す（閉扉予告）。**閉まり切るまで力行できない**ので、HUD の「実効」は
`切 力行カット`、「客用扉」は `閉扉中 40%` のように出る。

曲線では HUD に「カント / 過不足」と「ロール 軌道 + 車体」が出る。R600 のカント 75mm 区間なら
`75 mm 右上がり`（＝外軌が右）と `-4.03°` が表示され、車体はその上でさらにばねぶん傾く。
勾配区間では同じくピッチが「勾配 + 車体」に分かれる。

「乗客の振れ」は減衰振り子の角度で、括弧内の「遅れ」が瞬時の平衡角との差になる。
これが大きいほど乗客は振り回されている。B7 を一気に入れて G メータの振れ盤を見ると、
先端が平衡点を追い越して戻るのが軌跡に残る。

HUD のノッチ表示は **手元**（運転士が握っているハンドルの位置）と **実効**（保安装置・
戸閉め条件・ブレーキとの優先関係を通したあとに実際に主回路へ出る指令）を分けて出す。
力行ハンドルを入れているのに実効が「切」になる場合は、`力行カット` の表示とともに
その原因（保安装置の動作、ブレーキノッチとの重複、戸開）が読み取れる。

`O` で自動運転に入ると、HUD に装置の動作モード（力行 / 惰行 / 抑速 / 停止位置制御）と、
いま何を見て減速しているか、要求減速度と指令減速度が出る。切ったときは装置が握っていた
ノッチをそのままハンドル位置として引き継ぐので、制動中に切り替えても走り出さない。

## 物理モデルの要点

### 軌道線形

平面線形は曲率プロファイル κ(s) で定義し、方位角は θ(s) = θ₀ + ∫κ ds（解析的に厳密）、
平面位置は x = ∫cos θ ds, z = −∫sin θ ds をガウス・ルジャンドル求積で数値積分する。
直線・円曲線・緩和曲線（曲率が線形に変化）を同じ枠組みで扱える。
クロソイドの級数解と 10⁻⁶ の精度で一致することをテストで確認している。

縦断線形は勾配プロファイルの積分で高さを与える。縦曲線は勾配変化点を中心に
前後へ半分ずつ配置され、その区間の高さは s の 2 次関数（＝円曲線）になる。

### カント

カントは緩和曲線区間で逓減する。カント角は `φ = asin(C / G)` で、**外軌（曲線外側の
レール）が高いほど正**。曲率が正（左曲線）ならカントも正になる。一方、車体のロール角は
**右側が下がるほど正**という逆の約束なので、カントが車体に与えるロールは `−φ` になる。
描画も体感加速度もこの符号ひとつで決まるため、`apps/debugger/src/render/frame.ts` の
1 箇所だけで回転を作り、レール・まくらぎ・道床・車体・運転席カメラがすべてそこから
導かれるようにしてある（回帰テスト `apps/debugger/test/frame.test.ts`）。

軌道面内の非平衡左右加速度と均衡カントは厳密に整合する定義を採る。

```
a = v² κ · cos φ − g · sin φ                    非平衡左右加速度（正 = 外側へ）
tan φ_eq = v² κ / g,  C_eq = G · sin φ_eq       均衡カント（a = 0 になるカント）
C_d = C_eq − C                                   カント過不足（正 = 不足）
```

慣用式 `C = G V² / (127 R)` は `G · tan φ` に相当する小角度近似で、実用範囲では
厳密値より 0.5% ほど大きい。曲線の制限速度 `v = √((C + C_d,max) g R / G)` は
設計上の規則なのでデータ層で慣用式のまま扱う。

`cantDeficiency()` は**向き付き**の量（曲率と同符号なら外側へ超過遠心力）で、
右曲線では符号が反転する。実務で言う「カント不足量 [mm]」は左右によらない
スカラーなので、表示・警告・評価には `cantDeficiencyAmount()`（正 = 不足）を使う。

サンプル路線の曲線は実際の設計則に沿って与えてある。

| 曲線    | カント | 制限速度 | 均衡速度 | 制限速度でのカント不足 | C + C_d | 緩和曲線長          |
| ------- | ------ | -------- | -------- | ---------------------- | ------- | ------------------- |
| R600 左 | 75 mm  | 95 km/h  | 73 km/h  | 50 mm                  | 125 mm  | 80 m（逓減 1/1067） |
| R400 右 | 90 mm  | 80 km/h  | 66 km/h  | 43 mm                  | 133 mm  | 100 m（1/1111）     |

1067mm 軌間の上限（最大カント 105mm、最大カント不足 60mm、合計 165mm）に収まり、
緩和曲線長も設計則 `L ≥ 0.008 C V`（それぞれ 57m / 58m）を満たす。
均衡速度が制限速度の 0.77 / 0.82 倍というのも、カントを実際の運転速度に
合わせて決める実務の考え方と一致する。

### 列車ダイナミクス

車両ごとに位置と速度、輪軸ごとに角速度を状態として持つ。

- 車両: `m dv/dt = ΣF_creep + F_勾配 + F_連結器 − R_走行 − R_曲線`
- 輪軸: `J dω/dt = T_駆動 + T_摩擦 − r F_creep(ω, v)`（`|T_摩擦| ≤ T_ブレーキ`）

クリープ力はすべり率に対して極めて急峻なため、輪軸は**後退オイラー法を
ニュートン反復で解く**。これにより dt = 1ms でも発散しない。
回転部慣性は等価質量係数 γ から `J = γ m_自重 r² / 軸数` として求めるので、
一定引張力での加速度が `a = F / (m(1+γ))` に厳密に一致する（テスト済み）。

軸重は静的な等分配に加えて、台車間（車体重心高さ）と台車内（牽引装置高さ）の
荷重移動を考慮する。どの軸から空転するかがこれで決まる。

### 停止と保持（静止摩擦）

機械ブレーキの摩擦はクーロン摩擦なので、**静止摩擦（固着）を持つ**。`sgn(ω)` を
`tanh(ω/ω₀)` のような滑らかな関数で置き換えると低速でブレーキトルクが角速度に比例して
抜けてしまい、「停止直前に減速度がなだらかに消える」「勾配上で永久に転動し続ける」という
実車には無い挙動になる。そこで固着を陽に解く。

輪軸は、まず `ω = 0` を保つのに必要な摩擦トルクを求め、それがブレーキの容量に収まって
いれば固着させる（`|T_f| ≤ T_ブレーキ`）。収まらなければ滑り域として
`T_f = −T_ブレーキ·sgn(ω)` を固定して解く。

車輪が固着しているとき、レール面の力は輪軸のトルクと釣り合う**拘束力**になる。
輪軸のつり合いと粘着限界から、1 軸が受け持てる長手力は

```
F ∈ [(T_駆動 − T_ブレーキ)/r, (T_駆動 + T_ブレーキ)/r] ∩ [−μW, +μW]
```

の範囲になり、勾配と連結器の外力を打ち消す値がこの範囲に収まっていれば列車は動かない。
両端の意味がそのまま挙動になる。

- ブレーキを緩解すれば範囲は `T_駆動/r` の 1 点に潰れる。車輪が転がるので勾配上では必ず動き出す
- 非常ブレーキなら ±μW いっぱいまで使えるので、粘着が足りるかぎり停車を保つ
- 粘着やブレーキ力が足りなければ保持できず、滑り出す

結果として、停止の瞬間に減速度が段差で消える。この段差が乗客の**揺り戻し**になる。

### 粘着

```
ξ = (rω − v) / max(|v|, v_ref)
μ(x) = μ_k tanh(2x) + (μ_p − μ_k) · 2x/(1 + x²)      x = ξ / ξ_peak
μ_p(V) = μ₀ / (1 + kV) × 踏面状態係数 × 砂撒き係数
```

微小すべりで立ち上がり、ξ_peak 付近でピークを取り、大すべりで滑走摩擦係数へ
漸近する。この「ピークを越えると力が落ちる」形が空転・滑走を不安定現象にする。

### 曲線通過とアタック角（`packages/core/src/physics/curving.ts`）

同じクリープ曲線が**横方向**にも効く。1 つの台車の 2 本の輪軸は台車枠に平行に
保持されているので、曲線では両方を同時に半径方向へ向けられない。台車が円弧の弦に
沿って落ち着くとすると、台車中心から ±a（a = 固定軸距の半分）にある輪軸は
進行方向に対して傾いたまま転がることになる。

```
α = a κ + |y(s+a) − y(s−a)| / 2a          曲線ぶん + 通り狂いぶん
x = α / ξ_横飽和
軋りの駆動 = max(0, −dμ/dx) / (最大の負勾配 × 飽和比)
```

第 1 項が曲線、第 2 項が通り狂いである。第 2 項を**点の微分ではなく弦の傾きで**
取っているのは、台車が固定軸距より短い波長の狂いを追えないからで、微分でやると
波長 1m の細かい狂いが数 mrad に化けて直線でも軋みが鳴りっぱなしになる。

α が横クリープの飽和すべり角を越えると、粘着と同じ理屈で **μ の傾きが負**になる。
傾きが負ということは減衰が負ということなので、車輪の面外振動が自分で育つ —
これが曲線の軋み音（curve squeal）である。閾値は諸元だけで決まる:

| 場所               | 半径 | アタック角 | 鳴るか                         |
| ------------------ | ---- | ---------- | ------------------------------ |
| 本線の曲線         | R600 | 1.8mrad    | 鳴らない                       |
| 本線の曲線         | R400 | 2.6mrad    | 通り狂いが乗ったところだけ     |
| #12 分岐器のリード | R350 | 3.0mrad    | トングレールの遊間が乗って鳴る |
| #8 分岐器のリード  | R145 | 7.2mrad    | 確実に鳴く                     |

固定軸距 2.1m・飽和 3mrad なら鳴きはじめは R300 前後で、「曲線半径が固定軸距の
100〜200 倍を下回ると鳴きはじめる」という現場の目安と桁が合う。**分岐器を特別扱い
する分岐は 1 行も無い。** トングレールの遊間も護輪軌条の押し戻しも通り狂いとして
書かれているので、曲線とまったく同じ経路を通って出てくる。直進側では曲率が 0 で、
護輪軌条の押し戻しは軸距の弦で均されるため鳴らない — これも当てはめではなく結果である。

### 車体の動揺と体感加速度

揺れの原因を 2 つに分けて扱う。

**軌道狂い** は距離程 s の関数として、波長の異なる正弦波の重ね合わせで生成する。
振幅を波長に比例させることで、軌道狂いのパワースペクトル密度が空間周波数の
-3 乗に比例するという実測の傾向に合わせている。時間の関数ではないので、
同じ地点を何度通っても同じ揺れ方になる。

**車体の応答** は各自由度を 2 次系（固有振動数と減衰比）として積分する。

```
ẍ = ω²(x_target − x) − 2ζω ẋ      ω = 2πf
```

| 自由度 | 目標値（励振源）                             | 既定の固有振動数 |
| ------ | -------------------------------------------- | ---------------- |
| ロール | 軌道面の横加速度 × 車体傾斜率 + 水準狂い     | 0.85 Hz          |
| ピッチ | 前後加速度 × ピッチゲイン + 前後台車の高低差 | 1.35 Hz          |
| ヨー   | 前後台車の通り狂いの差                       | 1.5 Hz           |
| 左右   | 横加速度 × ゲイン + 通り狂いの平均           | 1.0 Hz           |
| 上下   | 前後台車の高低狂いの平均                     | 1.2 Hz           |

乗客が感じる比力は、水平面での比力（右向き `a_h = v²κ`、上向き `g`）を、
**カントと車体ロールの両方で傾いた床**の座標系へ射影して求める。

```
φ = φ_軌道 + φ_車体          φ_軌道 = −カント角、    φ_車体 = ばね上のロール（右下がりが正）
p = p_軌道 + p_車体          p_軌道 = −勾配角、      p_車体 = ばね上のピッチ（前下がりが正）

felt_lateral      = a_h · cos φ + g · sin φ
felt_longitudinal = g · sin p − a · cos p
felt_vertical     = (g · cos φ − a_h · sin φ) · cos p + 上下動の加速度
```

左右も前後も同じ形で、**傾いた床に沿う重力成分**が加速度に加わる。

車体傾斜率（フレキシビリティ係数、空気ばね車で 0.3 程度）が大きいほど、車体は
曲線外側へ余分に傾き、乗客が感じる横 G は軌道面の値より大きくなる。これが車体傾斜制御が
必要になる理由でもある。逆に均衡カントちょうどで通過すると横 G は 0 になり、
上下 G が `g / cos φ` へ増える（曲線で体が重く感じられる現象）。

前後方向で勾配の項が効くのは、たとえば **33‰ の下り勾配を惰行しているとき**。
加速度だけを見れば `a = +0.32 m/s²` だが、斜面に沿う重力成分がこれを打ち消すので
乗客はほとんど何も感じない（残るのは回転部慣性のぶんだけ）。逆に上り勾配で停車すると、
加速度は 0 でも後ろへ押される。

### 吊り革の振られ方（減衰振り子）

比力をそのまま角度に直す（`atan2(横G, 上下G)`）と、加速度が変わった瞬間に角度が飛び、
**加加速度（ジャーク）がまったく見えない**。吊り革は固有周期 1.5 秒程度の振り子で、
加速度に遅れて追従する。そこで車体座標系の左右面・前後面それぞれで減衰振り子を解く。

```
g_eff = hypot(f_i, f_z)
θ_eq  = atan2(f_i, f_z)                     瞬時の平衡角（= 加速度そのものの向き）
ω     = sqrt(g_eff / L)
θ̈     = −ω² sin(θ − θ_eq) − 2ζω θ̇ − φ̈_車体
```

- 復元項は非線形のまま。定常では `tan θ = f_i / f_z` に収束するので、減衰を強くすれば
  瞬時値表示に連続的に近づく
- `g_eff` を使うので、上下 G が増える曲線では振り子が硬くなる（周期が短くなる）
- `φ̈_車体` は車体のロール／ピッチ角加速度。吊り革の支点は車体と一緒に回るため、
  軌道狂いによる車体の揺れが吊り革を細かく揺らす

減衰は吊り革の支点の摩擦だけなので弱い。ステップ応答の行き過ぎ量は
`exp(−πζ/√(1−ζ²))` で決まり、既定の `ζ = 0.2` では 53%。急ブレーキで停車すると、
前へ振られていた吊り革が**その半分ほど後ろへ揺り戻してから**数回揺れて収まる。

### 立っている乗客（倒立振子 + 遅れのある姿勢制御）

吊り革は**物**なので振り子でよい。しかし**人は振り子ではない**。振り子は加速度が
ゆっくり変わっても速く変わっても同じだけ振られて同じように収まるが、人は違う。
加速度がゆっくり変われば先によりかかって耐え、急に変われば取り残されてよろける。
この差は乗り心地そのもの — つまり運転の質そのもの — なので、乗客だけは別の模型で解く。

上体を、足首を支点として重心高さ `h`（0.95m）に質量が集まった**倒立**振子とみなす。

```
θ̈ = (1/h)(f_z sin θ + f_i cos θ) − (f_z / h²) d − φ̈_車体
```

第 1 項は倒立振子の不安定性そのもの（傾くほど倒れる）で、吊り革と符号が逆になっている
のがこの模型の要である。第 2 項が姿勢制御で、`d` は**足圧中心（COP）**をくるぶし直下から
どれだけ動かしたか [m]。床反力の作用点をずらして足首まわりのモーメントを作るという、
実際のやり方をそのまま書いている。

`d = 0` の定常解は `θ* = −atan2(f_i, f_z)`、すなわち**押される向きへよりかかる**姿勢。
加速する電車の中で人が進行方向へ傾いて立っているのはこれで、吊り革が振られる向きとは逆になる。

制御はむだ時間つきの PD で、指令は支持基底面（爪先 12cm・踵 7cm・左右 8.5cm、
つかまっていれば +5cm）でクリップされる。

```
d_指令 = k_p e(t − τ) + k_d θ̇(t − τ),  e = θ − θ*,  k_p = 1.35 h,  τ = 0.14 s
d      → 一次遅れ（筋の立ち上がり 60ms）→ 支持基底面でクリップ
```

- `k_p > h` でなければ倒立振子の不安定性に勝てない（足関節スティフネスが体重 × 重心高さ
  を上回っていなければ立てない、という条件そのもの）
- **むだ時間 τ こそが「よろける」の正体**である。加速度が緩やかに変われば `θ*` もゆっくり
  動くので、τ があっても `e` は育たない。階段状に変われば `θ*` が飛び、τ のあいだ制御は
  前の状態のままなので上体はまるごと取り残される。先読みはしていない —
  「ゆっくりなら耐えられる」は予測ではなく、**遅れよりゆっくり動く目標には遅れが
  問題にならない**というだけのことである
- 微分ゲインは遅れの無い系で必要な値よりかなり大きい。むだ時間があると比例項が `k_p τ`
  ぶんの**負の減衰**として働くためで、人が「速く動いているほど強く踏ん張る」のは
  これを埋め合わせている

足圧中心を縁まで動かしても足りなくなったら、人は足を出す。判定には Hof の
**外挿重心**（extrapolated centre of mass）を使う。

```
XcoM = h(e + ė / ω₀),   ω₀ = √(f_z / h)
```

これが支持基底面の縁を越えたら、その場で立て直すことはもう不可能である。踏み出しは
0.35 秒（そのあいだは片足支持で支持基底面が狭い）、着地では外挿重心がちょうど新しい
支持基底面へ収まる位置へ足を置く。**足を出した回数**は運転評価の指標として記録される。

結果として、**同じ加速度でも変え方で乗客の運命が変わる**。

| 操作                     | 目標姿勢 θ\* | 追従の遅れ e | 結果                       |
| ------------------------ | ------------ | ------------ | -------------------------- |
| 一段ずつ刻む             | ゆっくり動く | ほぼ 0       | 静かによりかかるだけ       |
| フルノッチで一気に入れる | 飛ぶ         | 大きい       | 取り残されて倒れ、足が出る |

同じところまで加速しても、フルノッチで発車すれば足が出て、1 ノッチずつ入れれば出ない
（`packages/data/test/simulation.test.ts`）。逆に**ブレーキは一気に入れても足は出ない** —
BC 圧のむだ時間と込め時定数のせいで、減速度の立ち上がりが装置の側で鈍らされるためで、
よろけ具合の差は 1.4 倍にとどまる。乗客を放り出すのは、ブレーキの応答より速い変化
（分岐器の横 G の立ち上がり、パターンブレーキの投入、フルノッチ起動）のほうである。

### 分岐器（ポイント）

分岐器は 3 つの別々のものとして効く。

**1. 線形** — 分岐側へ開通していれば、その先はリード曲線（#12 なら R350）へ入る。
分岐器のリード曲線には**緩和曲線もカントも無い**ので、曲率が 0 から 1/R へ一段で
立ち上がる。本線の曲線（80〜100m の緩和曲線つき）とは、同じ横 G でも体への来方が
まるで違う。制限速度を超えて渡れば、階段状の横 G で立っている乗客はよろける。

寸法は番数 N ひとつで決まる。

```
クロッシング角 α = atan(1/N)     #8 → 7.13°、#12 → 4.76°
リード半径 R                     #8 → 145m、#12 → 350m（N² にほぼ比例）
リード長 = R α                   #12 → 29m（曲線を抜けるとちょうど α だけ向きが変わる）
分岐側の制限速度 = √(C_d g R / G)  許容カント不足 50mm で #8 → 25、#12 → 45km/h
```

許容カント不足が本線の曲線（60mm）より小さいのは、緩和曲線もカントも無いためである。
この 50mm という 1 つの値で、実際の在来線の分岐制限（#8 → 25、#10 → 35、#12 → 45km/h）が
そのまま出る。分岐制限は速度制限の 1 つなので、ATS-P の地上子も自動で配置される。

**2. 揺れ** — トングレール先端とクロッシング（ノーズ）は、**距離程の関数としての局所的な
軌道狂い**として扱う。軌道狂いと同じ扱いにすることで、車体動揺の側には手を入れずに
「そこを通ると揺れる」が出る。

- クロッシングの欠線（レールの途切れ）を車輪が渡る 5mm の落ち込み。欠線は**片方の
  レールにしか無い**ので、上下動だけでなく**水準狂いとして車体をロールさせる**。
  直進なら分岐側のレール、分岐側を通れば本線側のレールを踏むので、**開通方向で
  傾く向きが逆になる**
- トングレールでのフランジウェイの遊間ぶんの横のふらつきと、護輪軌条の押し戻し
- 可動ノーズクロッシングなら欠線が無いので衝撃は 1/4 になる

**3. 音** — 上と同じ 2 点で、軸ごとに衝撃音が鳴る。1 つの分岐器につき軸ごとに 2 回
（トングレール先端とクロッシング）なので、**「ガタン…ガタン」が対で来て、それが
軸の数だけ続く**。2 つの間隔はリード長 ÷ 速度そのものなので、番数の大きい分岐器ほど
離れて聞こえる。継目より深く落ちてばね下がまるごと上下するぶん、音は低く長い。

| 経路                             | 周波数 | 残る長さ | 聞こえ方 |
| -------------------------------- | ------ | -------- | -------- |
| 分岐器全体（長まくらぎ・道床）   | 55Hz   | 320ms    | ゴ〜     |
| 台車枠・軸箱が落ちて着く         | 180Hz  | 110ms    | ドン     |
| 車輪踏面と翼レール・ノーズの打撃 | 1100Hz | 22ms     | ガチャ   |

**進路は路線データで表す。** 分岐側へ開通していればその先は別の線形になるので、
「直進する進路」と「分岐する進路」は別々の路線データになる。分岐器そのもの
（位置・番数・寸法）はどちらの路線でも同じで、違うのは開通方向だけである。
同梱の試験線は 6300m の #12 片開き分岐器（右分岐・対向）を直進側／分岐側の
2 本の路線として持っており、シナリオを選ぶだけで走り比べられる。

### 表示

HUD はロールを「軌道 + 車体」、ピッチを「勾配 + 車体」に分けて出すので、傾きが
線形によるものか車体の揺れによるものかを区別できる。分岐器が近づけば、番数・分岐の
向き・開通方向・分岐側の制限速度が手前 1.5km から出る。G メータは 3 つの図で構成する。

- **振れ盤** — 吊り革の先端を真上から見た位置と軌跡。瞬時の平衡点を薄い十字で重ねてあり、
  両者を結ぶ線が「まだ振れ切っていない量」＝ジャークの効き具合になる。立っている乗客の
  支持余裕（外挿重心を支持基底面の縁で正規化した量）も同じ図に重ね、破線の円が
  「これ以上は足を出すしかない」縁になる
- **前面図** — カントで傾いた軌道面 → その上でロールした車体 → さらにその中で振られる
  吊り革と、逆向きによりかかって踏ん張る乗客、という 3 段が同時に見える。足元には
  支持基底面と足圧中心が出て、踏み出すと赤くなる
- **側面図** — 勾配で傾いた床 → 車体のピッチング → 前後の吊り革と乗客

### 駆動方式

同じ路線を同じように走らせても、主回路の作りが違えば走りは違う。3 方式を
`TractionSystem` の別実装として持ち、シナリオで選べるようにしてある。

|                  | VVVF インバータ                  | 抵抗制御                       | 電機子チョッパ                   |
| ---------------- | -------------------------------- | ------------------------------ | -------------------------------- |
| 電動機           | 三相誘導機                       | 直流直巻機                     | 直流直巻機                       |
| 引張力の決まり方 | 3 領域のトルク曲線を**指令**する | 電機子回路の**解**として出る   | 同左（電流を調節する）           |
| ノッチの意味     | トルク指令率                     | どの段まで進めてよいか         | 限流値の割合                     |
| 加速度曲線       | 平坦                             | 進段のたびに鋸歯・渡りで欠ける | 平坦                             |
| 電気ブレーキ     | 回生                             | 発電（抵抗器へ捨てる）         | 回生                             |
| 架線の受け入れ率 | 効く                             | **効かない**                   | 効く                             |
| 音を決める量     | 出力周波数・キャリア             | 回転数（キャリアが無い）       | チョッパ周波数（速度に依らない） |

#### 直流直巻電動機（`packages/core/src/traction/dcMotor.ts`）

誘導機と決定的に違うのは、**トルクも回転数も電機子回路から従属して出てくる**点で
ある。VVVF なら「定トルク → 定出力 → 特性領域」という曲線を諸元として与えられるが、
直流機でその曲線を与えてはいけない。曲線は結果であって原因ではない。

界磁巻線が電機子と直列につながっている（＝直巻）ので、界磁磁束は電機子電流そのものが
作る。鉄心の飽和を含めて磁化曲線を

```
φ(I) = I / (I + I_飽和)          0..1、飽和で 1 に漸近
```

と置くと、直巻機の 2 つの顔が 1 本の式から出る:

- 小電流 `φ ≒ I / I_飽和` → `T ∝ I²` — 起動時に大きな引張力が出る
- 大電流 `φ → 1` → `T ∝ I` — 飽和して他励機と同じになる

トルクと逆起電力は**同じ係数**で書く。

```
T = kΦ_max · φ(I) · β · I        β = 界磁率（弱め界磁で 1 未満）
E = kΦ_max · φ(I) · β · ω_電動機
```

こう書いてあるので `E·I = T·ω` が数値誤差の範囲で厳密に成り立つ。電気入力と機械出力を
別々に計算して食い違う、ということが起こらない。

電流は陽に積分する。φ が I に依存するせいで定常解は陰関数になるが、インダクタンスを
持たせて時間発展させれば解く必要がない。

```
R_合計 = m·R_a + R_外部,   L_合計 = m·L_a
I_ss   = (V_印加 − m·E) / R_合計
τ      = L_合計 / R_合計
I ← I_ss + (I − I_ss)·exp(−dt/τ)
```

積分は一次遅れの厳密解で行う。起動抵抗が入っている段では τ が数 ms まで小さくなるので、
陽的オイラーだと制御周期 10ms で発散してしまう。

諸元は**銘板**（定格電圧・定格電流・定格回転数）で書き、磁束定数はコンパイラが逆算する。

```
kΦ(I_定格) = (V_定格 − I_定格·R_a) / ω_定格
kΦ_max     = kΦ(I_定格) · (I_定格 + I_飽和) / I_定格
```

こうしておくと定格出力が自動的に銘板と一致する。路線データで曲線の制限速度を書かせない
のと同じ方針で、**計算で出る量はデータに書かせない**。

#### 抵抗制御（`packages/core/src/traction/resistor.ts`）

起動時は電動機に全電圧を掛けられない。逆起電力が無いので短絡に近い電流が流れてしまう。
起動抵抗を直列に入れて電流を抑え、速度が上がって電流が落ちるたびに抵抗を 1 段ずつ
短絡していく。これがカム軸の進段である。

進段の条件は**電流**である。電機子電流が進段電流を下回り、かつ最短滞留時間が経っていれば
1 段進む。この単純な規則から、実車の走りがそのまま出る:

1. 段が進むと外部抵抗が落ちるので、定常電流が跳ね上がる
2. 電機子回路の L/R 時定数で電流が立ち上がり、限流値付近に達する
3. 加速して逆起電力が上がるにつれ電流が落ちていく
4. 進段電流を下回ったところで次の段へ — 1 に戻る

引張力は電流で決まるので、この往復がそのまま**鋸歯**になる。`torqueRiseRate` などの
レートリミッタは抵抗制御では一切参照しない。掛けてしまえば鋸歯がならされて VVVF と
区別がつかなくなる。レートリミッタの役目は電機子回路のインダクタンスとカム軸の
回転速度が果たしている。

進段表はデータに書かない。段が切り替わる瞬間は回転数が変わらない＝逆起電力が同じなので、

```
R_合計,j · I_進段 = R_合計,j+1 · I_限流
  →  R_合計,j+1 = R_合計,j · (I_進段 / I_限流)
```

という公比一定の幾何級数になり、抵抗値は限流値と進段電流の比だけで決まってしまう。
**段数も設計者が決める数ではない。** 実車の段数がどれも似た数になるのはこのためである。
データに書くのは限流値・進段電流・つなぎ方・弱め界磁の段だけで、表はコンパイラが
組み立てる（同梱の抵抗制御車では直列 7 段 + 並列 8 段 + 弱め界磁 4 段の 19 段になる）。

抵抗を使い切ったら電動機のつなぎ方を組み替えて 1 台あたりの電圧を上げ、抵抗を入れ直して
同じことを繰り返す。**組替えのあいだは主回路を開く**必要があるので、そこだけトルクが
完全に抜ける — 加速中に一瞬つんのめる「渡りのショック」がこれである。抵抗を短絡する
だけの進段と、回路の形そのものを変える組替えの違いがここに出る。

再粘着制御は持たない。直巻機は空転すると回転が上がって逆起電力が増え、電流が落ち、
トルクが落ちる — **特性そのものが再粘着装置になっている**。空転の検知だけは表示のために
行うが、引張力を絞る制御は入れていない。

**発電ブレーキ**は電機子を制動抵抗へつなぐだけである。電流が界磁を作り、界磁が逆起電力を
作り、その逆起電力が電流を流す。φ の形のおかげで I が約分でき、閉じた式が出る:

```
I · R_合計 = m · kΦ_max · φ(I) · β · ω
  →  I = m · kΦ_max · β · ω / R_合計 − I_飽和
```

右辺が正になる速度より下では**自励しない**。実車の発電ブレーキが低速で落ちて空気
ブレーキへ渡していくのは、フェード曲線を引いているからではなく、この閾値そのものである
（同梱の車両では 28km/h あたり）。そして熱にして捨てるので、**架線の回生受け入れ率とは
無関係に効く**。回生失効という現象がそもそも起きないのが、この方式の数少ない長所である。

#### 電機子チョッパ制御（`packages/core/src/traction/chopper.ts`）

電動機は抵抗制御車とまったく同じ直流直巻機で、違うのは**電圧の作り方だけ**である。
起動抵抗で落として熱にする代わりに、サイリスタチョッパで架線電圧を刻む。

制御は電流調節器である。限流値を流すのに要る電圧を電機子回路の式から逆算し、それを
架線電圧で割ったものが通流率になる。

```
δ* = (m·E + I*·R_合計) / V_線        clamp[0, δ_max]
V_a = δ · V_線
```

δ が上限に貼り付いたら（＝もう電圧を上げられない）、そこから先は界磁を弱めて電流を保つ。
「起動から一定加速度 → 全通流 → 弱め界磁」という 3 段が、抵抗を 1 本も使わずに出る。
段が無いので引張力は連続で、同じ電動機を積んだ抵抗制御車と乗り比べると「刻みがあるか
無いか」の差だけが浮き上がる。

回生ブレーキは同じ回路を昇圧動作させる。昇圧比には `1/(1 − δ_max)` の上限があるので、
電動機側の電圧が架線電圧の `1 − δ_max` 倍を下回るとどうやっても架線へ押し返せない。
`regenFade*Speed` はその速度から決めている。抵抗制御の発電ブレーキと違い、**架線に
受け取り手がいなければ効かない**。

制動力の要求は**トルク**の要求である。トルクは電流に比例していない（低電流では 2 乗に
近い）ので、「制動力を半分にしたいから電流を半分にする」は誤りになる。要求トルクから
2 次方程式を解いて必要な電流を逆算している（`currentForTorque`）。

### ブレーキ

1. ノッチ → 指令減速度（定減速度制御）
2. 指令減速度 × 実際の等価質量 → 必要制動力（応荷重制御）
3. 空気ブレーキ指令を**先込め**する。回生が絞られてから込め始めると
   むだ時間と込め時定数のぶん減速度が落ち込むため、`むだ時間 + 込め時定数`
   だけ先の速度で見込まれる回生能力を基準に不足分を求める
4. BC 圧 = むだ時間 → 一次遅れ（込め／緩めで時定数が異なる）→ 摩擦材の μ(v)
5. 残りを電気ブレーキが受け持つ（空気が立ち上がるほど回生を絞る）
6. 滑走を検知した車の BC 圧を素早く抜き、収まったらゆっくり込め直す

回生絞り込み速度を跨ぐ受け渡しでは減速度がわずかに落ち込む。これは実車にも
現れる過渡であり、先込め制御によって指令値の 25% 以内に収まっている。

### 客用扉

指令に対して**有限の時間をかけて動く**。要点は 2 つある。

1 つは**戸閉連動**である。実車の力行回路は全部の扉が閉じて施錠されたことを確かめる
接点を通っているので、閉指令を出した瞬間ではなく、閉まり切ってから初めて力行できる。
ブレーキシリンダ圧や回生の受け渡しと同じで、指令と実出力を分けて時間発展させる。
自動運転もこれに従うので、扉が閉まるまでは発車しない。

もう 1 つは**閉扉予告**である。閉指令が出ると、まずドアチャイムが鳴り、少し置いてから
扉が動き出す。駆け込み乗車への予告であり、「ピンポーン…（間）…プシュー ガシャン」
という順番はこの予告時間そのものである。開くときは予告が要らないので、チャイムと
動き出しが同時になる。

閉扉の途中で開指令を出せば、その位置から開き直す。まだ閉まり切っていないので施錠も
されておらず、当然そのあいだ力行はできない。

### 走行音

音源ファイルは 1 つも使わない。**装置の仕組みから波形を作る**という点で、
ほかのモデルと同じ方針を取っている。

#### インバータの変調（`packages/core/src/traction/modulation.ts`）

まず「いま主回路がどういうスイッチングをしているか」を物理から求める。
これは引張力には一切影響しない — 同じ出力をどう作っているかだけの話である。

```
f_rotor = p · (ω_軸 · 歯車比) / 2π         p = 極対数
f_slip  = f_slip,定格 · (T / T_定格)        力行で正、回生で負
f₁      = f_rotor + f_slip                 インバータ出力周波数
M       = min(1, f₁ / f_base)              V/f 一定 → 定電圧（弱め界磁）
```

角速度は**動軸の実回転**から取る。したがって空転すれば電動機の回転が跳ね上がり、
音も一緒に跳ね上がる（実車で空転が耳で分かるのはこのため）。

キャリア（スイッチング）周波数は、低速では出力周波数と無関係な**非同期**、
ある周波数から先は**同期**モードでキャリアを出力の整数倍に固定し、速度が
上がるにつれてその整数を段階的に落とす。この段階の切り替わりが、日本の VVVF 車で
聞こえる「音程が上がっていって途中でガクッと落ちる」の正体である。
モードはヒステリシス付きで選ぶ（境界で往復すると実機では素子が壊れる）。

サンプル車両（GTO サイリスタ、4 極・歯車比 7.07・車輪径 0.86m）の梯子:

| f₁     | モード         | キャリア                  | 目安速度 | 実測                                    |
| ------ | -------------- | ------------------------- | -------- | --------------------------------------- |
| 〜18Hz | 非同期         | 250 → 350 → 480Hz（段階） | 〜12km/h | 3.4 / 5.4 / 7.1 / 8.8 km/h で段が変わる |
| 18〜28 | 同期 15 パルス | 270〜420Hz                | 〜18km/h | 12.2km/h                                |
| 28〜38 | 同期 9 パルス  | 252〜342Hz                | 〜25km/h | 19.3km/h                                |
| 38〜47 | 同期 5 パルス  | 190〜235Hz                | 〜31km/h | 25.2km/h                                |
| 47〜53 | 同期 3 パルス  | 141〜159Hz                | 〜35km/h | 32.2km/h                                |
| 53〜   | 一パルス       | —                         | 35km/h〜 | 35.9km/h                                |

素子・変調方式はすべて車両データ側のパラメータなので、キャリアの表を高く平坦に
すれば IGBT に、階段状にすれば音階インバータになる。走りは 1 ミリも変わらない。

#### PWM 波形から音へ（`packages/audio/src/dsp/inverterVoice.ts`）

発振器を並べてキャリアとサイドバンドを 1 本ずつ作るのではなく、AudioWorklet の中で
実機と同じ手順を 1 サンプルずつ踏む。

```
1. 三角波キャリア c(θc) と 3 相の正弦変調波 m_x(θ₁) を比較して相電圧 ±1 を作る
2. 線間中性点電圧 v_an = v_a − (v_a+v_b+v_c)/3
3. 磁束 λ = ∫v_an dt              固定子電圧はほぼ磁束の微分
4. 電磁半径力 ∝ λ²                マクスウェル応力は磁束密度の 2 乗
5. 構造共振（固定子鉄心・フレーム）を通して放射音にする
```

**4 の 2 乗が要**である。`λ = λ₁ + λ_h` を 2 乗すると交差項 `2λ₁λ_h` が現れるので、
キャリア ± 出力周波数のサイドバンドと 2f₁ の磁気音が、個別に作り込まなくても
自動的に出てくる。同期モードへの移行も、過変調も、一パルスの矩形波音も、
比較の結果として現れるだけで特別扱いは要らない。

実際に node でレンダしてスペクトルを測ると、教科書どおりの構造になっている
（f₁ = 30Hz、キャリア 450Hz、いずれもゲルツェル法での実測値）。

| 周波数          | パワー          | 意味                                    |
| --------------- | --------------- | --------------------------------------- |
| 60Hz            | 1.0e-3          | 2f₁ の磁気音                            |
| 420 / 480Hz     | 2.6e-6 / 2.1e-6 | キャリア ± f₁                           |
| 360 / 540Hz     | 2.1e-6 / 4.7e-6 | キャリア ± 3f₁                          |
| **450Hz**       | **2.7e-15**     | キャリアそのもの — 3 相で打ち消される   |
| **390 / 510Hz** | **2e-13**       | 偶数次サイドバンド — 同じく打ち消される |

磁束は 3 相の打ち消しで奇数次しか持たず、それを 2 乗した力は**必ず偶数次**になる。
「回転数の 2 倍のうなり」が実車で聞こえるのはこれである。

V/f 一定制御では変調率が `f₁/f_base` で上がるため、磁束 `M/f₁` は基底周波数まで
一定に保たれる。以降は変調率が飽和して磁束が `1/f₁` で落ちる。**低速でも音が痩せず、
弱め界磁に入ると磁気音が弱まる**という実機の関係が、この 1 行から出る。

ただし V/f 一定を素直に守ると `f₁ → 0` で電圧も 0 になり、磁束が立たない。実際には
電圧の一部が一次巻線の抵抗降下 `I·R₁` に食われるので、その分を上乗せしなければ
**起動時に定格トルクを出せる説明がつかない**。低周波電圧ブースト（`voltageBoost`）が
それで、降下は電流に比例するから上乗せも負荷に比例する:

```
M = min(1, f₁/f_base + ブースト × |トルク比|)
```

入れていなかったころは、起動の 1 音目だけが 17dB 落ち込んでいた。引張力はトルク特性の
側で決まっているので、この値を変えても**走りは変わらない**。変わるのは磁束、つまり
起動直後の磁気音の大きさだけである。

構造共振の表でいちばん下は**固定子の楕円モード（円周方向の次数 m = 2）**である。
半径力波が次数 m の変形を励振したときの振れ幅は `1/(m² − 1)²` に比例するので、m = 2 が
他を圧して大きく（m = 3 の 16 倍）、輪の曲げ剛性が最も低いのでいちばん低い周波数に来る。
電気機械の騒音でまず問題になるのは常にこのモードなのに、表がその上（620Hz）から
始まっていた。600Hz 以下には共振の裾しか無いところへ放射効率の落ちが重なるため、
**この帯に音程を持つ車両だけが不当に静かになる**という偏りが出ていた。

比較器の出力は理想的な矩形波なので、そのままの速度で作ると折り返しが可聴帯域に
落ちる。PWM 生成から 2 乗までを 4 倍オーバーサンプリングで行い、帯域が倍に
広がった後で低域通過させて間引く。

#### 音階インバータ

キャリア周波数がそのまま磁気音の音程になるので、`asyncCarrier` の折れ線を**平らな段の
階段**にし、段の高さを平均律の音名に合わせれば、そのまま音階として聞こえる。同梱の
「通勤形 4 両編成 音階インバータ」がそれで、**コアには 1 行も足していない** —
既定の GTO 車との違いは、段が 3 つ（250/350/480Hz）か 12 段（ソラシド レミファソ
ラシドレ）かだけである。

減速すると同じ階段を下りてくるのも、作り込んだ結果ではない。キャリアが出力周波数の
関数である以上、そうなるほかない。

階段は 196〜587Hz にあるので、上の 2 つ — 低周波電圧ブーストと m = 2 の楕円モード —
がまとめて効くのがこの車両である。どちらも音量のつまみではなく模型の欠けだったので、
埋めた結果として音階が聞こえるようになった。A 特性実効値での実測:

| 段    | 前     | 後     | 差       |
| ----- | ------ | ------ | -------- |
| ソ G3 | 0.0014 | 0.0100 | +17.1 dB |
| シ B3 | 0.0117 | 0.0200 | +4.7 dB  |
| レ D4 | 0.0315 | 0.0602 | +5.6 dB  |
| ラ A4 | 0.1595 | 0.2034 | +2.1 dB  |
| レ D5 | 0.0900 | 0.1153 | +2.2 dB  |

いちばん下の段がいちばん持ち上がる。**そこが実際にいちばん間違っていた**からで、
全体に倍率を掛けたのではこうはならない。

#### 客用扉

3 つの成分でできている。

- **ドアチャイム** — 完全 4 度の 2 音（B5 → F#5）を繰り返す。高いほうから低いほうへ
  下がるのが日本の車両で広く使われている形で、上がると呼び出し音に聞こえてしまう。
  鳴っている長さは扉装置が決めるので、音源側は「鳴っているあいだ鳴らす」だけでよい。
- **戸閉め装置の空気音** — 扉が動いているあいだだけ鳴る帯域雑音。閉めるときは排気を
  絞るぶん小さく、開くときは勢いよく抜けるので大きい。弁が開くのは速く抜け切るのは
  ゆっくりなので、包絡は立ち上がりと立ち下がりで時定数が違う。
- **戸当たり** — 閉まり切った瞬間の「ガシャン」と、開き切って戸袋に当たる音。どちらも
  撃力でモーダルに励振する。戸先ゴムがあるぶん接触器の進段音より低く、長く残る。
  開き切りは戸袋へ入って止まるだけなので、戸先どうしが突き当たる戸閉めより軽い。

車内で鳴る合図なので、チャイムの音量は走行音ではなく**運転台の報知音**（ATS チャイムと
打鐘）を物差しに合わせてある。

#### 抵抗制御とチョッパの音（`packages/audio/src/dsp/`）

直流機の音が VVVF といちばん違うのは、**キャリアが無い**ことである。音程を決める量が
回転数しかないので、力行しているあいだ音程は速度に比例して素直に上がり続け、途中で
飛んだり落ちたりしない。段が進んでも、界磁を弱めても、音程は変わらない（変わるのは
音量だけ）。抵抗制御車の走行音が「モーターがただ唸って上がっていく」ように聞こえるのは
このためである。音源は整流子片を渡るブラシの周波数（`片数 × 回転数/60`）で、
力は磁束 × 電流 ≒ 電流² なので、限流値制御で電流が一定な起動中は**音量が変わらず音程だけが
上がる**。

高域の傾きには気をつける必要がある。インバータ音では磁束の積分（利得 ∝ 1/f）が、
放射効率の +6dB/oct をちょうど打ち消していた。整流子音には積分が無いので、代わりに
**構造の質量制御域のロールオフ**を置く。共振より十分上では固定子とフレームは剛性ではなく
質量で応答が決まるからで、1 極（−6dB/oct）にすると一致周波数より上で正味
`−20·log₁₀f` — インバータ音とまったく同じ傾きになる。これを置かないと高域が上がりっぱなしに
なり、回転が上がるほど金属的で耳につく音になってしまう（逆に 2 極にすると高速域で
電動機の音がほとんど消えてしまい、これも実車と違う）。

転流の跳ねが尖っていないことも効く。ブラシは 1 片より広く整流子に当たっていて、転流する
コイルはその間ブラシに短絡されているため、電流は有限の時間をかけて移る。したがって
調波の重みは次数とともに落ち（およそ `1/n²`）、基音がいちばん強い。

**起動抵抗のうなり**は物理側が計算した「いま抵抗で捨てている電力」をそのまま音量にして
いる。だから段が進んで抵抗が短絡されるほど小さくなり、全短絡した段と弱め界磁域では
完全に消える。音量を別に決めているわけではない。

**カム軸の進段音**は接触器が閉じる短い打撃で、分岐器や継目と同じモーダル励振で作る。
床下の機器箱の中で金属が閉じる音なので、継目より軽く硬い。直並列の組替えだけは主接触器が
一斉に動くので、はっきり重い音になる。

**チョッパ音**もインバータ音と同じく波形から作る。通流率 δ の方形波を刻み、その電圧を
インダクタンスで積分してリップル電流を作り、力を電流の 2 乗として取り出す。すると
実車の 3 つの特徴が個別に作り込まなくても出てくる:

1. **音程が速度に依らない。** チョッパ周波数は固定なので、加速しても音程が上がらない
2. **倍音の構成が通流率で変わる。** 方形波の n 次成分は `sin(nπδ)/n` なので、δ が動くと
   音色だけが変わる
3. **全通流で消える。** δ → 1 では電圧が切れ目なく掛かるのでリップルが生まれない。
   チョッパ音が消えて整流子の音だけが残る

各音源の大きさは**インバータ音を物差しにして較正**してある。揃えていないと車両を
切り替えるたびに音量を取り直すことになるからで、ミキサのつまみ 1.0 での実測は
インバータ音に対して抵抗制御車が +2dB、チョッパ車が最大 +6dB に収まる。チョッパ車が
少し大きいのはチョッパ音のせいではなく、整流子の基音が 980Hz の構造共振を通過する
ためで、抵抗制御車にも同じ山がある。

チョッパ音は整流子の音と同じ桁（基音どうしで −6〜−2dB）で鳴るようにしてある。
埋もれてもいなければ電動機を覆い隠してもいない — この車の音のいちばんの特徴だからである。

#### そのほかの音源

| 音源             | 駆動する量                 | 速度依存                                                   |
| ---------------- | -------------------------- | ---------------------------------------------------------- |
| 歯車のかみ合い   | 電動機回転数 × 小歯車歯数  | 周波数が回転数に比例。1 回転ごとの歯形誤差でうなる         |
| 整流子・ブラシ   | 電動機回転数 × 整流子片数  | 直流機のみ。音程は回転数だけで決まり、段では変わらない     |
| ドアチャイム     | 扉の開閉指令               | 完全 4 度の 2 音。閉めるときは扉が動き出す前に鳴る         |
| 戸閉め装置       | 扉が動いているあいだ       | 閉めるときのほうが小さい（排気を絞るため）                 |
| 戸当たり         | 閉まり切る／開き切る瞬間   | 戸閉めのほうが重い。戸先ゴムのぶん接触器より低い           |
| 起動抵抗のうなり | 抵抗で捨てている電力       | 抵抗制御のみ。段が進むほど小さくなり、全短絡で消える       |
| カム軸の進段     | 進段・組替えの瞬間         | 抵抗制御のみ。組替えは主接触器が一斉に動くので重い         |
| チョッパ         | 通流率と電流リップル       | チョッパのみ。**音程は速度に依らず**、全通流で消える       |
| 転動音           | 車輪・レールの粗さ         | 30·log₁₀v（振幅 ∝ v^1.5）。重心も速度で上がる              |
| 風切り音         | 空力音                     | 60·log₁₀v（振幅 ∝ v³）。通勤形の速度域では転動音に埋もれる |
| レール波状摩耗   | 踏面の周期的な摩耗         | `v / 波長` の狭帯域の唸り。加速すると音程が上がる          |
| まくらぎ通過     | レールの支持剛性の周期変化 | `v / 0.6m` で転動音が脈動する                              |
| レール継目       | 軸が継目を踏む時刻         | 衝撃の強さ ∝ v^1.5                                         |
| ブレーキ摩擦     | 押付力 × すべり速度        | 止まる寸前に消えるのは速度が 0 になるから                  |
| 制輪子の鳴き     | 低速 × 高い押付力          | 摩擦係数の速度勾配が負になる領域の自励振動                 |
| 空気の込め／排気 | BC 圧の**変化率**          | 緩め（大気開放）のほうが込めより大きい                     |
| 空気圧縮機       | 元空気溜め圧               | 運転操作と無関係な周期で突然回り出す                       |
| 空気ばねのきしみ | 車体の上下・ロール速度     | ゴムのスティックスリップ。**遅く**擦れるときだけ鳴く       |
| 曲線の軋み音     | 輪軸のアタック角           | 車輪の面外モードの自励振動。**音程が速度に依らない**       |
| 保安装置の報知音 | ベル・チャイム・パターン   | 運転台の中で鳴るので距離減衰もマスクも受けない             |
| 警笛             | 吹鳴の操作                 | 空気笛 2 管の和音。圧力の立ち上がりで音程が動く            |
| トンネル         | 編成が坑内に入っている割合 | 合成した減衰雑音の IR で残響を付ける                       |

**惰行するとインバータ音だけが消えて歯車と転動音が残る。** これがインバータ音と
走行音の決定的な違いで、ノッチを切った瞬間に音程がすっと消えるのはこのため。

最後の段は「力 → 音」の変換で、ここが 2 つに分かれる。**構造共振**（固定子鉄心と
フレームのモード）が力を振動に変え、**放射効率**が振動を音に変える。放射効率は
一致周波数（曲げ波の速度が音速に追いつく周波数、鋼板で 2.5kHz 前後）より下では
f² に比例して低い — 板が動いても空気が横へ逃げてしまうためで、これを入れないと
高速域が実際よりはるかに静かになる。弱め界磁で磁束が 1/f₁ に落ちるので力は
−40·log₁₀f で減る一方、成分は高域へ動いていくので、放射効率の +6dB/oct が
その半分を打ち消す。実車で高速でも電動機の音が聞こえ続けるのはこの釣り合いによる。

ノッチの入切は、音量ではなく**ゲート（相電圧）**で表している。切れば素子が全部
オフになって電圧が 0 になり、磁束は還流ダイオードを通って電動機自身の時定数で
減衰する。つまり消え方そのものが過渡であって、包絡線を別に用意していない。
入れるときは逆に磁束が立ち上がる。**出力周波数はゲートが閉じているあいだも
回転子の周波数を渡し続ける** — 0 へ落とすと、磁束が積分（利得 ∝ 1/f）である
ために消えぎわで利得が跳ね上がり、80km/h では定常の 14 倍もの掃引音（「ピッ」という
異音）が出る。実機の再投入も、回っている回転子の速度に合った周波数から入る。

#### レールから来る音

レール継目は、軸ごとに「前ステップと今ステップのあいだを跨いだか」で判定し、
フレーム内の位置を小数で求めて**サンプル精度**で予約する。60fps に丸めると 16ms も
ばらついて「ガタン ゴトン」の間隔が台車の寸法を映さなくなる。1 両 4 軸なら
前台車の 2 軸（固定軸距 2.1m）→ 間を空けて → 後台車の 2 軸、という 2 拍ずつの
並びになり、続いて次の車両が同じ継目を踏む。

1 回の衝撃は**別々の経路**を通って音になる。経路ごとに関わる質量とばねが違うので、
周波数だけでなく**残る長さ**も違う。低次のモードほど減衰が小さいという構造振動の
一般則がそのまま「ガタン」の重さになっている。

| 経路                         | 周波数 | 残る長さ | 聞こえ方 |
| ---------------------------- | ------ | -------- | -------- |
| ばね上（車体）とレールの曲げ | 80Hz   | 250ms    | ガ〜     |
| 台車枠・軸箱（ばね下）       | 230Hz  | 90ms     | タン     |
| 車輪踏面とレール腹部         | 1500Hz | 18ms     | カッ     |

3 つを同じ短い時定数で減衰させていたころは低域が高域と一緒に切れてしまい、
「カタッ カタッ」という軽い音にしかならなかった（低域/高域 +7.8dB、−20dB まで
110ms）。経路ごとに分けた結果 +23dB / 200ms になっている。

分岐器（ポイント）はこれと同じ仕組みだが、鳴り方が違う。軸ごとに 2 回 —
トングレール先端とクロッシング — 踏むので「ガタン…ガタン」が対で来る。欠線を渡る
落ち込みは継目の段差より深く、ばね下がまるごと上下するので、経路も低いほうへ寄る
（55 / 180 / 1100Hz、いちばん長い成分で 320ms）。別の音源にしてあるので、ミキサで
継目とは独立に音量を調整でき、メータでも別々に測れる。

継目の無いロングレール区間では、代わりに**レール自身から来る 2 つの音**が主役になる。
どちらも周波数が速度に比例するので、加速すると音程が上がっていく。

- **波状摩耗（コルゲーション）** — 踏面には走行を重ねるうちに波長数 cm の周期的な
  摩耗ができる。粗さのスペクトルにその波長の峰が立つので、転動音に `v / 波長` の
  狭帯域の唸りが乗る。55mm なら 60km/h で 303Hz、120km/h で 606Hz。深さは路線
  データの区間属性なので、「この区間は唸る」を線路の側で表せる
- **まくらぎ通過** — レールはまくらぎの上では硬く、間では柔らかい。この支持剛性の
  周期変化が接触力を脈動させるので、転動音の包絡が `v / 0.6m` で揺れる

#### 運転台の中で鳴るもの

保安装置の報知音（打鈴・チャイム・パターン接近ブザー）と警笛だけは、**運転台の
中の装置**が音源なので距離減衰を受けない。走行音に埋もれてしまっては装置の意味が
無いのだから、走行音より大きいのは都合ではなく設計である。実測でも 80km/h の
走行音に対して報知音が +4dB、警笛が +8dB（いずれも A 特性）に置いてある。

打鈴は電磁ベルで、電磁石がハンマーを引き、接点が切れて戻り、また引く、という
自励で毎秒 32 回連打する。鐘の部分音は整数比に**ならない**ので、「ジリリリ」が
音程を持たずに耳につく。正弦を重ねただけでは電子音になってしまう。

警笛は空気笛（タイフォン）で、圧縮空気がリードを振動させる。倍音が豊かなことと、
2 管の周波数がわずかにずれていてうなりが乗ることが「ブザーとの違い」を作る。
吹き始めは弁が開いてから圧力が立ち上がるまで音程がわずかに低い。

空気ばねのきしみは、分厚いゴムのベローズが金属座と擦れる音である。ゴムは静摩擦が
動摩擦よりかなり大きいので擦れが滑らかに進まず、固着と滑りを繰り返す — 制輪子の
鳴きとまったく同じスティックスリップで、**遅く擦れるときにだけ**鳴く。速く滑ると
固着する暇が無いので鳴かない。車体の上下速度とロール角速度から左右の空気ばねの
ストローク速度を求めて駆動するので、停車前後や低速の曲線でだけ耳に届く。

#### 曲線の軋み音（`packages/audio/src/dsp/curveSquealVoice.ts`）

制輪子の鳴きや空気ばねのきしみと同じスティックスリップだが、**鳴っている物が違う**。
ここで振動しているのは車輪そのもの — ほとんど減衰の無い鋼の円板 — で、加振しているのは
輪軸が横を向いて転がることによる横クリープである（駆動の求め方は上の「曲線通過と
アタック角」）。したがってほかの音源と性質が 4 つ違う。

- **ほとんど純音**。自励するのは減衰がいちばん負になったモード 1 つだけなので、
  帯域雑音を濾すのではなく**限界サイクル**として合成している。ここが制輪子の鳴きと
  作りが違うところで、鳴きは帯域雑音で足りる
- **音程が速度に依らない**。決めているのは車輪の固有振動数（860mm 車輪の面外 4 節径、
  約 1150Hz）であって、転動音や歯車のように回転で決まるのではない。加速しながら
  曲線を抜けても音程は動かない
- **育つのに時間が要り、消えるのは速い**（時定数 0.22s / 0.05s）。負減衰で指数的に
  育つのに対し、負減衰でなくなればあとは残響が落ちるだけだからである。この非対称の
  おかげで、**長く続く曲線では鳴き、一瞬で通り過ぎる不整では鳴かない**という差が
  当てはめ無しに出る
- **雨や雪でほとんど止む**。水膜が摩擦の負勾配をならすためで、粘着が 35% 落ちる程度の
  話では説明がつかない。粘着係数の倍率とは別の表を持たせてある

固着と滑りの時間は等しくない（固着しているほうが長く、滑りは一気に起きる）ので、
飽和させる前に偏りを足してある。左右対称に歪ませると奇数次の倍音しか出ず、実際の
軋りが持つ濁りにならない。振れ幅が大きいほど飽和が深くなるため、**大きい軋りほど
倍音が濃くなって耳障りになる**という関係もそのまま出る。

#### 音量バランス

音源どうしの音量は**耳ではなく実測で**決めてある。耳で合わせると、そのとき鳴って
いない音源を基準にしてしまう。実際、空気圧縮機は停車中に合わせたせいで 80km/h の
走行音より大きくなっていた（rms 0.076 対 0.067）。走行音を基準に測り直して 10dB 下へ
置き、`packages/audio/test/synth.test.ts` の回帰テストで固定してある。

運転台の `音量バランス` に調整用のつまみとメータがある。メータは**混ざる前の**
音源ごとの実効値（`TrainNoiseSynth.readLevels`）なので、「うるさい」と感じたものが
本当にその音源なのか、走行音に対してどれだけ大きいのかが数値で分かる。

走行装置は歯車・転動音・風切りを別々の音源として持つ。**音源の位置が違う**ため
まとめられない — 歯車は M 車の床下にしか無いので運転台からは編成の中ほどの
距離だけ離れており、転動音は運転台の真下の軸からも来る。分けて測って初めて、
それまで見えていなかった 2 つの誤りが分かった。

|                  | 分ける前                | 分けたあと                                                |
| ---------------- | ----------------------- | --------------------------------------------------------- |
| 歯車 vs 転動音   | 歯車が 120km/h まで支配 | 逆転点が 50km/h（低速では歯車、高速では転動音）           |
| 風切り vs 転動音 | 90km/h で風切りが逆転   | 最高速度でも 10dB 下（空力音が支配するのは 250km/h 以上） |

力行と惰行の差を決めるつまみが 2 つある。どちらも仕組みのある量である。

- **インバータの負荷追従** — V/f 一定制御では磁束が保たれるので、実機の磁気音は
  負荷でそれほど変わらない。0 にすればゲートが開いているあいだ一定になる。
  惰行ではどのみちゲートが閉じるので音は消える
- **歯車の負荷追従** — 裏を返せば「惰行のとき歯車が全負荷の何割を受け持つと
  見なすか」。惰行でも回転部の慣性トルクが歯面に掛かるので 0 にはならない

#### 層の分け方

| 層               | 置き場所                      | 性質                                                          |
| ---------------- | ----------------------------- | ------------------------------------------------------------- |
| 装置の物理       | `packages/core`               | 決定論・DOM 非依存・HUD とグラフに出る                        |
| DSP              | `packages/audio` の素のクラス | Web Audio 非依存・**node でレンダしてスペクトルを検定できる** |
| Web Audio の配線 | `apps/debugger/src/audio/`    | テストしない薄い殻                                            |

`render/frame.ts`（純粋・テスト済み）の上に `TrackScene`（three.js・テスト不能）が
乗っているのと同じ構造。合成の中身を `AudioWorkletProcessor` から切り離してあるので、
ワークレットは 60 行ほどの殻でしかない。

#### 背面タブでは音声を親時計にする

ブラウザは背面のタブで `requestAnimationFrame` を止め、タイマも 1 分に 1 回まで絞る。
シミュレーションを描画フレームから進めていると、そこで**時間が止まる**。すると
鳴りっぱなしの音（転動音・インバータ）は最後の状態のまま鳴り続け、イベントで鳴る音
（継目・分岐器・進段・戸当たり）だけが消える — 一部の音が出なくなったように聞こえる
のはこれである。

一方 **AudioWorklet は音声スレッドで動き続ける**。音を出しているタブはブラウザの
凍結対象からも外れるし、ワークレットからの `postMessage` はタイマ絞りの対象外なので、
背面のあいだだけワークレットが返す**レンダ済みの音声秒数**を親時計に使えばよい
（`TrainAudio.onClock`）。`visibilitychange` で切り替え、背面では絵と HUD を更新せず
シミュレーションと音のパラメータだけを進める。二重に進めないよう、背面のあいだは
描画フレーム側が先頭で戻る。

実測（4 倍速で 5 秒ぶん背面に置いた場合）:

```
背面へ回る前 : 経過 66.0s   608.2m
背面中 (HUD) : 経過 67.7s   625.2m   ← 描画は止まっているので更新されない
戻った直後   : 経過 89.8s  1151.3m   ← 背面のあいだも走り続けている
```

TypeScript で書いたワークレットは `?worker&url` で独立チャンクにバンドルさせて読み込む
（`new URL('./x.ts', import.meta.url)` はアセット扱いになり、ブラウザへ TypeScript が
そのまま届いて失敗する）。ビルド後の資産を `OfflineAudioContext` で回して、node の
テストと同じスペクトルが出ることを確認してある。

### 速度制限は列車の長さで解ける

制限速度は距離程 → 速度の階段関数だが、それを引くのは**先頭端の 1 点ではなく
在線範囲 [最後部, 先頭端]** で、その区間にかかっている最も低い値を採る
（`occupiedSpeedLimit`）。制限は先頭が入った時点で効きはじめ、**最後部が抜けるまで
解けない**。曲線の中に車体が残っているうちに加速してよい理由は無いので、これは
取扱の決まりごとである以前に物理の話である。閉塞の在線判定が最後部で閉塞を
開放するのと同じで、列車を点ではなく長さのあるものとして扱っている。

効きは小さくない。試験線の R400（4200〜5100m で 80km/h）を 4 両編成（80m）で抜けると:

```
先頭 5100m  最後部 5020m  → 80km/h（まだ曲線の中）
先頭 5180m  最後部 5100m  → 110km/h（ここで解ける）
```

先頭端で引いていれば 80m 手前で解けていた。80km/h なら 3.6 秒ぶんで、自動運転は
その間ずっと力行を始められない。分岐器の制限は制限区間のほうが編成長より短いことすら
あり、そこでは**在線範囲で引くかどうかが制限の長さそのものを決める**。

この値は `Simulation.currentSpeedLimit` の 1 か所で決まり、保安装置（ATS-P / ATC）の
照査速度の上限・自動運転の目標速度・HUD・グラフのすべてへ同じものが配られる。

### 保安装置

- **ATS-SN**: ロング地上子で警報 → 5 秒以内に確認扱いが無ければ非常。
  直下地上子を停止現示で通過すると即時非常。確認扱いさえすれば冒進できてしまう
  という性質も含めて再現している。
- **ATS-P**: 地上子から目標地点までの距離と目標速度を受け取り、車上でパターンを
  生成して連続照査する。パターン速度は応答時間 t_r を含む
  `v² = v_t² + 2a(d − margin − v·t_r)` の**厳密解**
  `v = −a t_r + √(a²t_r² + v_t² + 2a(d − margin))` で求める。
  停止信号・速度制限・線路終端・信号冒進に対応。
- **ATC**: 段階式（現示速度以下に落ちるまで緩解しない）とデジタル式
  （停止点からの一段ブレーキパターン）。
- **EB 装置**: 無操作の監視 → 警報 → 非常。

地上子の通過は「その瞬間に一致したか」ではなく**前ステップ位置と現ステップ位置の
区間を跨いだか**で判定するため、高速走行でも取りこぼさない。

列車が信号機を通過した瞬間、その列車自身が次の閉塞に入るため信号は停止現示へ
変わる。冒進判定には「まだ手前の閉塞にいた時点の現示」を使い、正常に進行現示で
通過した列車を誤判定しないようにしている。

停止現示の手前で止まった列車は、パターンの余裕距離の内側に次の地上子が無く、
パターン速度も 0 なので、そのままでは現示がアップしても動き出せない。停車中に
限り、現示アップでその信号のパターンを解放する（実機の直下地上子による消去に相当）。

### 自動運転（ATO / TASC）

`packages/core/src/operation/autoDrive.ts`。運転士の代わりに `ControlInput` を組み立てる
だけの装置で、物理にも保安装置にも手を入れない。したがって自動運転で走らせても、
出てくる挙動は手動運転とまったく同じ物理モデルの上の結果になる。

設計は「**不自然なブレーキの入切をしない**」と「**停止の衝撃を小さくしたまま停止位置に
収める**」の 2 点を軸にしている。

**1. 速度ではなく必要減速度で考える**

「目標速度を超えたらブレーキ、下回ったら緩解」という制御は、目標速度の周りで必ず
ブレーキを入切する。そこで前方の減速目標（速度制限・停止現示・停止位置）に対して

```
a_req = (v² − v_t²) / 2(d − margin − v·t_lag)
```

という**その目標に届くのに必要な減速度**を求め、それがそのまま出るノッチを選ぶ。
必要減速度どおりに減速しているかぎり a_req は一定に保たれるので、ノッチを動かす
必要がない。空走時間 t_lag は込める前は応答時間そのもの、込めたあとは 0 へ減らす
（込めたあとも引き続けると、目標へ近づくほど必要減速度が過大に出てノッチが
際限なく深くなる）。

**2. 勾配と走行抵抗を打ち消してから指令する**

ブレーキ装置の指令減速度は「ブレーキが受け持つぶん」であり、実際の減速度には勾配と
走行抵抗が加わる。指令値から勾配ぶんを差し引いておくと、下り勾配でもノッチを
入れっぱなしのまま速度が保たれる。33‰ の下り勾配は電気ブレーキだけの**抑速**で
受け持つので、空気ブレーキは 1 度も入切しない。

**3. 止まる直前は減速度そのものを絞る（衝撃緩和）**

停止の衝撃は「止まった瞬間の減速度」がそのまま前後衝動になる。速度に対する目標減速度を

```
a(v) = a_final + (a_stop − a_final)·min(v / v_ease, 1)
```

と定め、その形のまま止まったときの制動距離を解析的に求める。絞り込み域では
`a(v) = a_f + c·v` なので

```
D(v) = ∫₀^v u/(a_f + c u) du = v/c − (a_f/c²)·ln(1 + c v / a_f)
```

となる。残距離 d に対する指令は `a(v)·D(v)/d` でよい。ちょうど良い位置（d = D(v)）なら
そのまま a(v) が出て、ずれていれば比例して補正される。これは一定減速度の必要減速度
`a = v²/2d` の自然な拡張であり、**停止位置の精度を落とさずに**止まる瞬間の減速度だけを
a_final まで落とせる。ノッチは B5 → B4 → B3 → B2 → B1 と自然に緩んでいく。

到達点 `a_final` は**最弱ノッチ B1 の減速度**に採る。停止制動中はブレーキを抜かない
（抜くと込め直しで必ず衝動が出る）ので、止まる瞬間に残っているのは B1 であり、
それより小さい値を狙っても届かないし、大きい値を狙えば B2 以上を込めたまま止まって
その段のぶんがそのまま前後衝動になる。早めに B1 相当まで指令を落とすことで、
空気ブレーキの応答（約 1 秒）が止まるまでに収まりきる。

そのほか:

- ノッチは 1 段ぶんの減速度に対する不感帯と最短間隔つきでしか動かさない。込めるときは
  一度に 2 段までで、足りなければ短い間隔で続ける（電気ブレーキは指令に即座に応じる
  ので、深いノッチを一息に入れると同じだけの段差が減速度に出る）
- 指令に対して実際に出ている減速度の比を覚えておき、雨・雪で滑走防止装置が働いて
  効きが落ちているぶんを割り増して補う。ただし絞り込み域では割り増さない
  （粘着が戻った瞬間に過大な減速度となって現れるため）
- 保安装置の照査速度も速度の上限に入れる。自動運転装置が保安装置に止められる、
  というのが運転としても保安としても最悪で、そこだけ突然の常用最大が入ってしまう
- 停車時分と発時刻の両方を満たしてから戸閉めし、戸閉め確認の間をおいて発車する。
  終着駅では発車しない。ATS-SN 区間では警報に確認扱いをする
- 空転・滑走を検知したら砂を撒く

試験線を自動運転で走らせた実測（晴天・4 両）:

| 指標                     | 値                                      |
| ------------------------ | --------------------------------------- |
| 停止位置誤差             | −0.04m / −0.15m（許容 1m）              |
| 止まった瞬間の減速度     | 0.07〜0.14 m/s²（常用最大の 1/14〜1/7） |
| ブレーキを込めた回数     | 4 回（3 停車 + 起点の停止保持）         |
| ブレーキノッチの操作回数 | 21 回（7km・3 停車）                    |
| 保安装置の動作           | 0 回                                    |

降雪（粘着が落ち、滑走防止装置が動作し続ける条件）でも停止位置誤差は 0.25m 以内に
収まる。ブレーキの効きの推定が働くため。

## 決定論

コアは `Date.now()` も `Math.random()` も使わない。乱数はシード付き mulberry32、
時刻は引数で渡す。未消化時間は整数マイクロ秒で保持するため、`step()` の呼び出し
間隔（フレームレート）を変えても結果がビット単位で一致する。

したがって「シナリオ ID + シード + 入力の変化列」だけで走行を完全に再現できる。
ビューアの「記録を保存 / 読込」はこれを使っている。

## データ形式

路線・車両・シナリオは zod スキーマで定義し、**現場で使われる単位**
（km/h・‰・mm・t・kgf/t・kPa・km/h/s）で書く。コンパイラが SI へ変換する。
経験式の係数はコードに埋めず、すべてデータ側のパラメータとして持つ。

路線データからは次が自動生成される:

- 曲線の制限速度（許容カント不足から `v = √((C + C_d) g R / G)`）
- 分岐器の寸法（番数から α = atan(1/N)・リード半径・リード長・全長）と分岐側の制限速度
- ATS-P の地上子（信号機・速度制限の手前の指定距離へ。分岐制限にも付く）
- ATS-SN の地上子（ロング・直下）
- 閉塞区間（信号機の位置から導出）

車両データの主回路は `kind` による判別可能ユニオンで、`vvvf` / `resistor` / `chopper` の
どれかを選ぶ。方式ごとに諸元がまるで違う（片方には電流も抵抗も無く、もう片方には
すべり周波数もパルスモードも無い）ので、`kind` は省略できない — 既定値を埋めると入力の
型が潰れて、車両データを書いた時点での型検査が効かなくなるためである。

直流機の車両データからは次が自動生成される:

- 磁束定数 kΦ_max（銘板の定格電圧・電流・回転数から逆算。定格出力が自動的に一致する）
- 抵抗制御の進段表（限流値と進段電流の比を公比とする幾何級数。段数もここで決まる）
- 各ノッチの止まり位置（省略時は全段をノッチ数で等分）

客用扉は `door` に開閉の時間・閉扉予告の時間・チャイムの有無と長さを書く。省略すれば
空気式両開き扉の代表値になる。

同梱サンプル: 架空の試験線（8km、R600/R400 曲線、25‰ 上り・33‰ 下り、トンネル、
駅 3、閉塞信号 8、6300m に #12 片開き分岐器）と、同じ路線を走る 4 種類の 4 両編成:

| 車両                           | 制御方式          | 起動加速度 | 電気ブレーキ | 最高速度 |
| ------------------------------ | ----------------- | ---------- | ------------ | -------- |
| 通勤形 4 両編成                | VVVF インバータ   | 3.3km/h/s  | 回生         | 120km/h  |
| 通勤形 4 両編成 抵抗制御       | 抵抗制御（19 段） | 2.38km/h/s | 発電         | 100km/h  |
| 通勤形 4 両編成 電機子チョッパ | 電機子チョッパ    | 2.81km/h/s | 回生         | 110km/h  |
| 通勤形 4 両編成 音階インバータ | VVVF インバータ   | 3.3km/h/s  | 回生         | 120km/h  |

音階インバータ車は既定の通勤形と**走行性能がまったく同じ**で、変調の諸元だけが違う。
常用最大減速度はいずれも 3.5km/h/s、非常 4.5km/h/s。抵抗制御車とチョッパ車は**同じ
直流直巻電動機**（375V・350A・1630rpm 級）を積んでいるので、乗り比べると電圧の作り方の
違いだけが浮き上がる。抵抗制御車だけは応荷重制御を持たず、混んでいるほど加速が鈍る。

分岐器の先は開通方向で線形が変わるので、試験線は**直進側と分岐側の 2 本の路線データ**
として持つ（`buildTestLine(branch)` が共通部分から両方を組み立てる）。シナリオ
「試験線 分岐器（直進）」「試験線 分岐器（分岐側へ）」はどちらも中原駅から発車するので、
分岐器の通り比べがすぐにできる。

新しい路線を足すには `packages/data/src/assets/` に定義を書き、
`createDefaultLibrary()` へ登録する。

## 検証

`npm test` で 460 件超のテストが走る。主なもの:

**解析解との突き合わせ**

- 惰行減速が走行抵抗の常微分方程式を 4 次ルンゲ・クッタで積分した解と一致
- 勾配のみで `a = g sinθ / (1+γ)`
- 一定引張力で `a = F / (m(1+γ))`
- 曲線抵抗が `f / R` に一致し、半径に反比例
- 円曲線の弧長・座標、クロソイドの級数解、縦曲線の高さ
- 停止距離が `v²/2a` + 空走距離の範囲に収まる
- ATS-P パターンが 2 次方程式の厳密解と一致

**現象テスト**

- 降雪条件の全ノッチ起動で空転が発生し、再粘着制御が引張力を絞る
- 砂撒きで粘着が回復する
- 粘着条件が悪いほど非常制動距離が延びる（乾燥 168m → 降雪 267m → 落葉 342m）
- 滑走防止装置を切ると制動距離が悪化する
- 停止直前までブレーキ力が抜けず、止まった瞬間に減速度が段差で消える
- 非常ブレーキで勾配上に停車すると 1 分間 1mm も動かない。緩解すれば転動し、
  ブレーキ力や粘着が足りなければ保持できない
- 電空協調の受け渡しで減速度が保たれる／回生失効しても空気が補う
- 先行列車が進むと後方の信号が段階的に現示アップする
- ATS-P が停止信号の手前で列車を止め、非常ブレーキには至らない
- 停止現示の手前で止まった列車が、現示アップ後に発進できる
- **速度制限は先頭が入った時点で効き、最後部が抜けるまで解けない**（制限が明ける
  位置が先頭端で引いた場合より編成長ぶん先になり、自動運転もそこまで力行しない）
- 編成より短い一時制限が編成の中にすっぽり収まっていても拾える

**駆動方式**

- 直流直巻機の電力が保存する（`E·I = T·ω` が全域で厳密に一致）
- 小電流でトルクが電流の 2 乗、飽和後は電流に比例
- 電機子回路の時定数が `L/R` に一致し、刻みが時定数より大きくても発散しない
- 発電ブレーキの自励電流が `I·R = m·kΦ·φ(I)·ω` を満たし、閾値速度より下では 0
- 抵抗制御の段が単調に、電流が進段電流を下回ったときだけ、最短滞留時間を守って進む
- 進段のたびに電流が限流値まで跳ね返り、進段電流まで落ちる（＝引張力の鋸歯）
- 直並列の組替えのあいだ引張力が完全に抜ける（渡り）
- 起動抵抗で捨てている電力が段とともに減り、全短絡で 0 になる
- **抵抗制御の発電ブレーキは架線の回生受け入れ率を変えても変わらない**
  （回生の VVVF・チョッパは受け入れ率に比例する）
- チョッパの電機子電圧が `δ·V_線/m` に一致し、限流値制御中の加速度のばらつきが 5% 以内
- 弱め界磁は通流率が上限に貼り付いたあとにだけ始まり、下限より下がらない
- 進段表の隣接段の抵抗比が `進段電流/限流値` の公比に一致し、各つなぎの初段は
  起動時に限流値がちょうど流れる値になっている
- ノッチの止まり位置がすべて全短絡の段（抵抗を残したまま走れない）
- 磁束定数が銘板の定格点を再現する（375V・350A・1630rpm → 約 120kW）
- 整流子音の音程が回転数だけで決まり、チョッパ音の音程は速度を変えても動かない
- 起動抵抗を短絡するとうなりの帯域の電力が落ち、全通流ではチョッパ音が消える
- 直流機の音の A 特性実効値がインバータ音と同じ範囲に収まり、回転数を上げても
  跳ね上がらない（**高域が上がりっぱなしになって耳につく**という不具合の回帰テスト）
- スペクトルが高域へ向かって落ち、4kHz 以上の量がインバータ音と同じ桁に収まる
- チョッパ音が整流子音に埋もれず、かといって覆い隠しもしない

**客用扉**

- 開指令ですぐ動き出し、閉指令ではまず予告があって扉はまだ動かない
- 閉じ切って施錠されて初めて戸閉連動が成立する（それまで引張力は 0 のまま）
- 閉指令から力行できるまでに「予告 + 閉扉」の時間がかかる
- 閉扉の途中で開指令を出せば、その位置から開き直し、施錠はされない
- チャイムは開閉どちらでも鳴り、指定の時間だけで止まる
- 自動運転でも扉が開閉し、チャイムが鳴り、扉が閉まるまで発車しない
- 扉の開閉が決定論的（同じ入力なら同じ時刻に施錠される）
- ドアチャイムが完全 4 度の 2 音で、高いほうが先に鳴る
- 戸閉めの戸当たりが開き切りより重く、接触器の進段音より低い

**音階インバータ**

- キャリアの段が平均律の音名になっていて、隣り合う段が全音か半音
- 出力周波数を上げるとキャリアが階段状に上り、下る向きへは動かない
- 減速すると同じ階段を下りてくる
- **走りが既定の通勤形とビット単位で一致する**（変調は引張力に関与しない）
- 起動時も変調率が 0 にならない（一次抵抗降下ぶんのブースト）、上乗せは負荷に比例する

**曲線の軋み音**

- アタック角が `a/R` になり、軸距が短いほど小さい
- 通り狂いは前後の輪軸を結ぶ**弦の傾き**で効き、軸距より短い波長は均されて消える
- 鳴きはじめる半径が諸元から R300 前後に決まり、境目を越えると急に立ち上がる
- **R600 では鳴らず、R400 では通り狂いと重なったところだけ断続的に鳴る**
- **分岐器を直進で渡っても鳴らず、分岐側へ渡ると鳴る**（曲率も通り狂いも違うため）
- すべりきってしまえば負勾配が消えるので、また静かになる
- 濡れたレール・降雪ではほとんど鳴らない
- 止まっていれば鳴らない。速度を上げても音程も強さも変わらない
- 大きい軋りほど倍音が濃い。一瞬の不整では立ち上がりきらない
- 鳴っているあいだは転動音を覆うが、飽和させるほどではない

**自動運転**

- 起点から終点まで自分で走り、全駅の停止位置に**所定内**（許容 1m）で止まる
- 止まる瞬間の減速度が常用最大の 1/5 以下（＝停車の衝撃緩和）
- 止まる直前ほどブレーキノッチが浅くなる
- ブレーキを込め直す回数が停車回数程度に収まる
- 33‰ の下り勾配を抑速で通過し、そのあいだ空気ブレーキを 1 度も入切しない
- 降雪でブレーキが効きにくくても停止位置に収まる（効きの推定が働く）
- 停止現示の手前で自分で止まり、現示アップで自分で発進する
- 停車時分と発時刻の両方を満たしてから発車する
- ATS-SN 区間では確認扱いを行い、非常ブレーキに至らない
- 保安装置（パターン・非常・EB）を一度も動作させずに走り切る
- 呼び出し間隔（フレームレート）を変えても状態ハッシュが一致する

- 曲線で車体が外側へロールし、体感横 G が軌道面の値を上回る
- 車体傾斜率を 0 にすると体感横 G が軌道面の値と一致する
- 加速で乗客は後ろへ、制動で前へ押され、車体がピッチングする
- 軌道狂いが大きいほど揺れが大きく、狂いゼロなら揺れない

**勾配と吊り革の振れ**

- 上り勾配で停車していると、加速度 0 でも乗客は後ろへ押される
- **33‰ を自由に転がっているときは前後の比力がほぼ 0**（勾配の重力成分が入っている証拠。
  抜けていると `-a = -0.32 m/s²` と出る）
- 一定加速度で振り子が `tan θ = a/g` へ収束し、平衡角は瞬時値と一致する
- 加速度を変えた直後は平衡角に届いていない（＝加加速度が見える）
- 減衰を弱くすると行き過ぎ、強くすると行き過ぎない
- 減衰をほぼ 0 にすると固有周期が `2π√(L/g)` に一致する
- 制動が急に切れる（＝停車する）と、前へ振られていた乗客が半分ほど後ろへ揺り戻す
- 振り子が短いほど速く追従する
- 制動では前へ、力行では後ろへ振れる

**立っている乗客**

- 一定の加速度では押される向きへ `tan θ* = a/g` だけよりかかり、足圧中心は
  くるぶしの近くへ戻る（吊り革とは**逆向き**に傾く）
- **同じ加速度でも、階段状に変えればよろけて足が出て、3 秒かけて変えれば
  よろけ具合が 1/10 以下になる**（この模型の目的そのもの）
- 吊り革のほうは変え方によらず同じところへ落ち着く（人と物の違い）
- 反応のむだ時間を 0 にすると階段状の入力でもよろけない（よろけの原因の同定）
- つかまっていれば同じ操作でよろけない
- 踵側の支持基底面が狭いので、後ろへ押される力行のほうがよろけやすい
- よろけても足を出せば立て直し、最後は静かによりかかった姿勢へ落ち着く
- フルノッチで発車すると足が出て、1 ノッチずつ入れれば出ない（実車の走行で）

**分岐器**

- 番数からクロッシング角 `tan α = 1/N`、リード半径（#8 → 145m、#12 → 350m）、
  リード長 `R α`、全長が決まる
- 分岐側の制限速度が許容カント不足 50mm から #8 → 25、#10 → 35、#12 → 45km/h になる
- リード曲線を抜けると、ちょうどクロッシング角のぶんだけ向きが変わる
- 分岐側の線形には緩和曲線もカントも無い（横 G が階段状に立ち上がる根拠）
- 分岐制限に ATS-P の地上子が自動配置される（手前 500/300/150/50m）
- 区間を一気に跨いでもトングレールとクロッシングを取りこぼさない
- **欠線を踏むレールが開通方向で入れ替わり、水準狂いの符号が逆になる**
- 直進側でも分岐器を通れば車体が揺れる（制限が無いので最高速度のまま渡れる）
- 分岐側を制限超過（90km/h）で渡ると横 G が 1.5 m/s² を超えて乗客がよろける
- 制限速度（45km/h）まで落として渡ればよろけない
- 分岐器の衝撃音がレール継目より低く長く残り、走行音に混ざっても突出する
- トングレールの衝撃はクロッシングより軽く、継目とは別の音源として測れる

**走行音（node でオフラインレンダしてスペクトルを測る）**

- 非同期モードでキャリア ± f₁ と ± 3f₁ にサイドバンドが立つ
- 3 相の打ち消しでキャリアそのものと偶数次サイドバンドが消える
  （1 相だけで作っている実装ならここで落ちる）
- 電磁力が出力周波数の**偶数倍にしか現れない**
- 同期モードでは全成分が f₁ の整数倍に乗り、その間には何も無い（位相ロックの確認）
- 一パルスではキャリアの帯が消え、低次の偶数次高調波だけになる
- 弱め界磁で磁気音が弱まり、基底周波数以下では低速でも痩せない
- **最高速度でも電動機の音が走行音に埋もれきらない**（A 特性で測る。放射効率と
  2.4kHz 以上の構造モードが無かったころは 27dB 下に沈んで聞こえなくなっていた）
- オーバーサンプリングを切ると折り返し成分が増える
- 歯車のかみ合い周波数とその高調波、歯形誤差による 1 回転ごとの側帯波
- 惰行しても歯車の音が消えない／電動機が回っていなければ歯車は無音
- 転動音が速度 2 倍で 9dB 増える（30·log₁₀v）
- 風切り音が速度 2 倍で 18dB 増え（60·log₁₀v）、最高速度でも転動音より 6dB 以上下
- **低速では歯車、高速では転動音が支配する**（まとめて 1 つの音量にしていたころは
  歯車が高速域まで支配したままだった、という回帰テスト）
- 継目の衝撃が予約したサンプル位置ちょうどから鳴り、**走行音に混ざっても突出する**
  （帯域通過の正規化で衝撃が埋もれるという不具合の回帰テスト）
- 継目の衝撃で**低い成分ほど長く残り**、低域・中域が高域より強い
  （すべて同じ時定数で減衰させて「カタッ」と軽くなっていたことの回帰テスト）
- 「ガタン ゴトン」の間隔が固定軸距・台車中心間距離と一致する
- ロングレール区間では継目が 1 つも出ない／逆走でも取りこぼさない
- 波状摩耗が `v / 波長` に唸りを作り、速度を変えると峰が動く／削正されたレールでは唸らない
- まくらぎ通過で転動音の包絡が `v / 0.6m` の周期で脈動する
- 空気ばねのきしみが「動いてはいるが遅い」ときにだけ出る（速く滑ると鳴かない）
- 打鈴・チャイム・ブザーが独立に鳴り、いずれも 80km/h の走行音より大きい
- 打鈴がハンマーの打数で脈動する（持続音になっていない）
- 警笛が 2 管の和音になっていて倍音を持ち、離すと圧力が抜けて消える
- 空気圧縮機が断続運転し、ブレーキを使うほど早く回り出す
- **ノッチを切っても入れても、過渡が定常より大きくならない**
  （出力周波数を 0 へ落として掃引音が出るという不具合の回帰テスト）
- 空気圧縮機が 80km/h の走行音より 6dB 以上小さく、かつ聞こえないほどでもない
- レベルメータが混ざる前の値を音源ごとに返す

**カント**

- 均衡カントが釣り合い条件 `tan φ = v²κ/g` を満たし、そのとき非平衡横加速度が厳密に 0
- 均衡カント通過時は体感横 G が 0、体感上下 G が `g / cos φ`（1G より重い）
- 停車中の曲線ではカント超過となり、乗客は曲線内側へ引かれる
- 描画の基準座標系で、左曲線は右側が上がり、右曲線は左側が上がる
  （車体とレールが逆向きに傾くバグの回帰テスト）
- 基準座標系が正規直交で、勾配区間でも軌道面が軌道に垂直になる

**性質テスト**

- 同一入力・異なるフレームレートで状態ハッシュが完全一致
- 軌道狂いは距離程の関数なので、同じ地点では常に同じ値になる
- 記録した入力の再生で同じ走行になる
- 連結器を硬くすると多質点モードが剛体モードへ漸近する

**性能**

`npm run bench` の実測で、4 両編成（16 軸）を物理 1kHz・装置制御 100Hz で回して
リアルタイム比 約 100 倍（10 秒ぶんの走行を 96ms）。多質点モードと単一質点モードの
差はほとんど無く、計算量は輪軸のニュートン反復が支配している。

## ビューア

- **運転席一人称視点** — 先頭車の前端から 1550mm 後ろ・車体中心から左へ 700mm・
  床面（レール面上 1130mm）から 1200mm という、実物の運転士の目の位置。車体動揺を
  そのままカメラに反映する（補間しない）ので、曲線でのロールも軌道狂いによる揺れも
  視界に出る。内装はカメラの子として取り付けてあるため、実車と同じく
  「内装は視界の中で静止し、窓の外だけが揺れる」。
- **外部視点**（追跡・側面・俯瞰・自由）— 列車と線路の関係を確かめる検証用。
- **実寸の構造物** — レール・まくらぎ・道床・架線・信号機・ホーム・車両を、
  形の似せ方ではなく**実物の寸法**から組み立てる（下記）。
- **昼間の沿線景観** — グラデーションの空、緑地、樹木・建物（シードから決定論的に
  配置）、トンネル覆工と照明、距離標・勾配標。
- **加速度メータ** — 吊り革の振れと乗客の支持余裕を 1 枚に重ねた振れ盤（軌跡付き）、
  ロール角ぶん傾いた車体断面に吊り革と立っている乗客（足圧中心つき）を描いた前面図、
  ピッチングと前後の傾きを示す側面図。数値ではなく「乗客がどちらへどれだけ
  振られ、どれだけ踏ん張っているか」を直接見せる。
- **時系列グラフ** — 速度・制限・ATS-P パターン、ノッチ、引張力と電空の分担、
  抵抗の内訳、BC 圧、すべり率と再粘着制御、主回路、体感加速度と車体ロール、
  連結器力と車体の揺れ。主回路の帯は**制御方式で系列が入れ替わる**（VVVF は
  出力周波数・キャリア・パルス数、抵抗制御は段・電機子電流・界磁率・直列台数、
  チョッパは通流率・電機子電流・界磁率・リップル）。抵抗制御車で力行すると、
  引張力の帯にそのまま鋸歯が出る。
- **走行音** — 主回路（インバータ／抵抗制御／チョッパ）・主電動機・歯車・転動音・
  客用扉とドアチャイム・レール継目・分岐器・曲線の軋み音・ブレーキ・空気・補機・
  風切り・トンネルの反響。HUD の「変調」「制御」の行とグラフの「主回路」帯を見れば、
  鳴っている音が仕様どおりかを目で確かめられる。ミキサのレベルメータは混ざる前の
  実効値なので、いま何が鳴っているかがそのまま読める（R400 の曲線と分岐側の分岐器で
  「曲線の軋み音」だけが立つのが目で分かる）。
  タブを背面に回してもシミュレーションは止まらない（音声を親時計に切り替える）。
- **自動運転** — `O` で入切。装置の動作モードと、いま何を見て減速しているか、
  要求減速度と指令減速度を HUD に出す。手動運転と見比べれば、ノッチの入切の
  少なさと、止まる瞬間の減速度の小ささが G メータの振れ盤にそのまま出る。

### 3D モデルの寸法

見た目を「それらしく」作るのではなく、日本の在来線（狭軌 1067mm・直流 1500V・
20m 級通勤形）の実寸から組み立てる。寸法は `apps/debugger/src/render/dimensions.ts`
に出典つきで集約してあり、各モジュールはそこからしか値を取らない。

| 対象           | 実物どおりにしてある点                                                                                                                                                                                                                                                               |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| レール         | 50kgN（高さ 153・底部幅 127・頭部幅 65・腹部厚 15mm）の断面を線形に沿って掃引。線ではなく立体なので、頭頂面が光り腹部に陰が出る。レール中心は軌間の外へ頭部幅の半分だけ出る                                                                                                          |
| まくらぎ       | PC まくらぎ 3 号（長さ 2000・高さ 190mm）を本線 1 級線の 25m あたり 44 本で敷く。レール座に締結装置が付く                                                                                                                                                                            |
| 道床・路盤     | まくらぎ下 250mm・肩幅 400mm・のり面 1:1.5 の道床を、路盤肩 600mm と盛土のり面で受ける                                                                                                                                                                                               |
| レール継目     | 路線データの継目間隔をそのまま読むので、**「ガタン ゴトン」が鳴る位置と目に見える継目が一致する**。ロングレール区間には現れない                                                                                                                                                      |
| 分岐器         | 先端が尖るトングレール・リードレール・クロッシング（ノーズ）・護輪軌条・電気転てつ機                                                                                                                                                                                                 |
| 架線           | シンプルカテナリ。トロリ線はレール面上 5000mm で**高さ一定**、その上のちょう架線が径間 50m の中央で 800mm たるみ、ハンガーが 5m ごとに両者を結ぶ。トロリ線は支持点ごとに ±200mm の偏位でジグザグに振れる。電化柱には可動ブラケット（主管・振止金具・曲線引・碍子）が付く             |
| トンネルの架線 | 単線トンネルの内空にはちょう架線を吊る高さが取れないため、トンネル区間だけ**剛体電車線**（覆工から直接支える T 形材）に変わる。トロリ線そのものは内外で 1 本に続く                                                                                                                   |

| 車両           | 連結面間 20000mm・車体長 19500mm・車体幅 2950mm の裾絞り車体、床面高さ 1130mm、屋根高さ 3655mm（肩 R450mm）。側扉 4 枚（幅 1300mm・中心間隔 4820mm）、台車中心間 13800mm・固定軸距 2100mm・車輪径 860mm。動力車は塗り分けではなく**パンタグラフと床下の主回路箱**で見分ける          |

### 質感

テクスチャは画像ファイルを 1 枚も持たず、すべてその場でキャンバスに描いて作る
（`apps/debugger/src/render/textures.ts`）。要点は**実寸で貼る**ことで、掃引形状の
UV は m 単位で入れてあるため、テクスチャ側に「1 枚が何 m ぶんか」を渡すだけで
模様の大きさが実物に合う（砕石は 40mm、ホームの平板は 300mm、覆工の打継目は 10.5m）。
描いた絵の明暗はそのまま高さと見なして法線マップに変換するので、色だけでなく
凹凸の陰影も出る。

| 面               | 1 枚の実寸        | 描いているもの                                     |
| ---------------- | ----------------- | -------------------------------------------------- |
| バラスト         | 1.2m              | 20〜60mm に砕いた角ばった石と、隙間に落ちた石粉    |
| 覆工コンクリート | 10.5m × 断面 1 周 | 打継目、側壁下部の黒い汚れ、天端の煤、漏水の白い筋 |
| ホームの床       | 1.2m              | 300mm 角の平板と目地、歩かれてすり減ったむら       |
| 点字ブロック     | 0.3m              | 点状突起 5 × 5 と、ホーム内側を示す内方線          |
| 折板屋根         | 2.4m              | 山と谷（法線マップで折りが立つ）                   |
| PC まくらぎ      | 0.9m              | 高強度コンクリートと、レール座まわりの油と錆       |
| 錆びた鋼         | 1.2m              | レールの腹部・継目板・信号機の柱・締結装置         |
| 建物の外壁       | 1 棟              | 窓の列と各階の帯                                   |
| 地面             | 14m               | 草のまだらと地肌                                   |

文字も同じくキャンバスに描く。駅名標には駅名が、距離標にはキロ程が、勾配標には
‰ の値が、信号機の番号板には閉塞番号が、実際に読める形で入る。

そのほか、質感に効いているもの:

- **環境マップ** — 空と地面のグラデーションを焼いて映り込みの元にする。これが無いと
  金属は「映すものが無い」ために黒く沈む。レールの頭頂面・ステンレスの車体・
  架線金具・窓ガラスが光るのはこれによる。
- **影** — 太陽が影を落とす。ただし 8km の路線全体を 1 枚の影の地図に収めることは
  できないので、焼く範囲を列車の周り 90m に絞り、光源が列車を追いかける。落とす側も
  線路の上に立っているもの（列車・ホームと上屋・信号機・電化柱）に絞ってある。
- **光のにじみ** — 自ら光るもの（信号の灯火・前照灯・トンネル照明・ホームの蛍光灯）には
  加算合成のにじみを重ねる。トンネルの照明は覆工に落ちる光の輪も描くので、
  光源が壁を照らしているように見える。
