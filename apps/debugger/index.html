操作
Z / A: 力行 +/−   Q: 制動側へ 1 段   S: 即 N   W: B1
. / ,: ブレーキ N → 抑速 → B1 → …   1: 非常
ノッチのキーは長押しで段が進む（非常へは自動で入らない）。ワンハンドルでは Q が N を越えてブレーキ側へ入る（A は N で止まる）
Space: 警笛 / X: 砂撒き
Enter・Delete: 確認扱い（EB 復帰）/ 2: 保安装置復帰（停止中）
↑ / ↓: 逆転ハンドル 前 / 後（停止中・力行切のみ）
PageDown / PageUp: ドア開 / 閉
- : 前照灯 / L: 減光 / V: ワイパー / Y: 耐雪ブレーキ
C: 視点（巡回）/ U: 表示の入切
O: 自動運転（ATO）の入切
P: 一時停止 / F: 1 ステップ / [ ]: 速度倍率 / M: 消音
手元のノッチが効かないときは HUD の「実効」行を確認（保安装置・戸開・逆転機でカットされる）
